# Seedance 共同事件切片合同

当目标为 Seedance 2.0 或 2.5 时读取。版本参数由对应模块决定，本文件只规定两者共享的 Prompt 组织方式。

## 核心判断

模型需要知道的不是“每几秒是什么状态”，而是当前切片发生了什么可见变化。每片只设一个主要变化，其他动作都服务于它。

按以下顺序组织：

```text
[风格]
[参考]
[起始状态]
[本片发生的变化]
[镜头]
[结束状态·供下一片承接]
[对白]
[声音]
[必须不变]
[可自由发挥]
```

### 起始状态

只写第一可见时刻已经成立的事实：人物位置、姿态、身体朝向、视线、空间关系、光线、摄影机状态与关键道具状态。

### 本片发生的变化

使用可拍、可见、可验收的动词，按因果顺序写：

1. 谁先触发动作；
2. 对象或另一角色如何响应；
3. 环境、道具或身体状态怎样改变；
4. 结果如何落到最后一帧。

多人物场景明确 Primary Mover 与 Secondary Reactor。避免只写“紧张、危险、史诗、悲伤”等静态评价。

### 镜头

先声明一镜到底或明确切换次数，再写景别、机位、运动、焦点及空间揭示。摄影机动作必须有叙事动机，不同时给互相冲突的运镜。

### 结束状态

写出最后一帧真正可见的角色、姿态、位置、空间、光线、道具和摄影机状态。它是跨片接口，不是情绪总结。

## 双重承接

多切片必须同时满足：

1. 上一片 `[结束状态·供下一片承接]` 逐字复制为下一片 `[起始状态]`；
2. 上一片实际导出的末帧作为下一片第一优先承接参考。

“逐字复制”只针对边界状态段，不表示复制上一片全部参考、动作或制作笔记。已经离场或不再影响当前画面的旧上下文不要继续携带。

若单张末帧不足以锁定紧密动作咬合，在版本与 method 合法的前提下使用首尾帧模式。

## Reference Role Map

相关参考按当前切片需要增加，每份只承担一个主要职责：

```text
@Ref1 = 承接帧，只负责空间、光线和入口状态连续
@Ref2 = 主角身份，只负责脸、体型与服装
@Ref3 = 场景，只负责空间结构
@Ref4 = 核心静帧，只负责构图与色调
@Ref5+ = 其他角色、道具、视角或状态；逐项声明唯一职责
```

承接帧不能覆盖正式角色身份；角色图不负责场景或另一角色；场景图不负责角色身份；构图图不负责修改 Canon。多视角可以共存，但必须拆清职责。

“相关参考全给”与“最小必要资产”并不冲突：前者要求不随意删掉已有的有效参考，后者要求不为假设性风险机械制造新资产。

## 声音与约束

- 对白写角色名、原文、情绪、语速、停顿和同步可见表演。
- Ambience、Foley、SFX、音乐分层；Foley 对齐实际动作。
- `[必须不变]` 只锁核心 Canon 和连续性。
- `[可自由发挥]` 明确模型可以补充的次要细节。
- 有独立 negative prompt 字段时才使用负向词；否则写成正向目标状态。
