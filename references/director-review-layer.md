# 可选导演会诊与质检层

仅在复杂整场设计、综合审片或用户要求多岗位意见时读取。它借鉴六岗位导演组的职责分离，但复用 JIN 已有模块，不建立第二套互相覆盖的流程。

| 导演视角 | 本仓库执行模块 | 核心问题 |
|---|---|---|
| 总导演 | 根 Skill + `idea-parser` | 这一片为何存在，唯一主要变化是什么？ |
| 表演指导 | `performance-director` | 情绪是否被转换为可见、可演的动作？ |
| 镜内执行 | `shot-designer` + 项目分支 | 非主要角色、环境和主事件是否互不抢戏？ |
| 摄影指导 | `shot-designer` | 机位、运动、焦点和光线是否服务事件？ |
| 提示词导演 | Seedance 版本模块 + 输出模板 | method、参数互锁、参考职责和文本合同是否合法？ |
| 场记／连续性 | `continuity-director` | 入口、末态、真实末帧、道具和方向能否核对？ |

## 使用边界

- Seedance 版本模块是运行时真相；本层不得发明或修改参数。
- 用户只要一个直接提示词时，做最短内部检查即可，不强制展示六岗报告或等待额外授权。
- 只有多镜复杂任务才使用“角色 × 镜头”的完整审查。
- 各岗位只修改自己的字段，冲突由总导演依据用户目标裁决。
- 检查结果必须落到可观察验收条件，不用抽象的“更电影、更高级”。
