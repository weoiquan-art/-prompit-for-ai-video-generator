# T1a 第一帧与具体化
条目：编号 名称｜适用范围｜把握[证据]；写法；避免。图例与编号索引：[evidence/README](../evidence/README.md)。

**C01·C02·C36 第一帧锚点｜通用｜中[重复；Chibi 记录]**
写法：核心事件成立的距离就是第一帧：谁在位、手里拿着什么、镜头在哪一侧都写清；同时写入画范围、朝向、视线、背景流动方向、镜头相对运动，并让它们一致。例：乱雪近景右侧、膝盖以上入画，仰头看上方，身体正立沿岩壁高速下坠；岩纹向上掠过；镜头快速后退。身体朝向与视线分开写；人物第一帧就在场，除非剧情要空镜；环境方向落成画面轴线（镜头朝向、左边是什么、右边是什么）。
避免：只写入画范围不写朝向（脸向下、世界歪斜）；用单个部位限定入画（"腿部入画"只拍到脚）；把远处发现、走近、缩放、转头寻找当免费铺垫（它们吃秒数）；在镜头位置之前单写"傍晚""暖光"；入画范围也可能被执行得更近或更远，要看成片。

**C35 具体压过抽象｜通用｜中高[Chibi 记录；重复；JIN 经验]**
写法：把抽象意图译成第一帧看得见的空间关系、身体状态和动作过程，按因果写：外部刺激 → 人物先泄漏的可见反应 → 身体接管 → 环境或道具证明 → 留下结果状态；只写当前景别看得见的证据（背面镜头改写头肩、手、脊背、重心）。交付前删掉"路过""温馨"等抽象词，只读第一帧和动作句，生成的故事还是不是要的。
避免：具体空间句偷改意图（写"路过"又写"远处出现、继续向前、随距离接近"，成片变成走向她们）；"截断面""半截"让山变圆柱；注意具体要求会压过总括（屏幕写"妈"压过"无画面文字"）；Chibi 多为 2.0、乱雪是 2.5，跨版本是否一样不知道。

**C27 前景局部入画与高低关系｜通用｜中低[单次]**
写法：从两人之间或肩旁拍向主体，让他们以前景局部入画；写明谁是主体、谁高谁低。例：两名外星人以前景局部入画，男主坐在路边成为画面主体；三人形成明确的高低关系。
避免：只写"三个人在场"不写谁在前景、谁是主体、谁高谁低；注意仅 2 个镜头有截图，外形差别大的角色不易混淆。
