# T3 动作与接触（通用）
条目：编号 名称｜适用范围｜把握[证据]；写法；避免。图例与编号索引：[evidence/README](../evidence/README.md)。打斗编排见 [T3f](t3f-fight.md)；接触类型、物理推演、特效载体见 [T3p](t3p-physics.md)。

**O10 动作要有过程｜通用｜中[旧·确认；检索：舞台格斗教学资料]**
写法：关键动作写 触发或发力起点 → 中间变化或接触 → 衰减与结果状态；可细分五拍：预备（重心、步伐、视线先到目标）、出手（发力顺序、路径、接触点）、跟随（不在接触点戛然而止）、反应（受力者身体被带动）、恢复（脚落稳、重心回、视线对上）。发力顺序脚 → 腿 → 髋 → 躯干 → 肩 → 臂 → 手 → 武器，视频里写重心下压、前脚蹬出、髋转、肩沉、手腕翻。高难动作用关键状态组织（起始 → 关键动作 → 接触／受力 → 落地／恢复），简单动作直接写连续过程，不切成姿势列表。
避免：用"跑过去、震惊、打斗、猛攻、击飞"这类结果词代替过程；写关节角度；每次接触后都停住（结果可以仍在滑行、转动）。

**C09·C16·C39 接触与持有闭合｜通用；脱手与武器连接待判断｜中[单次＋检索；重复；Chibi 记录]**
写法：先有接触和撞击证据（火花、震动、衣发被带起），再写受力者的反应（单独一句，主语是受力者），最后才脱手或松手。脱手五步：被制住停住 → 接触点撞击 → 持握者的手被震开 → 武器离手沿明确方向飞出 → 手臂和身体有反应。武器始终连着手：握持、刃节解锁、接触结果三项都写。递接：持有 → 递出 → 对方接触并承重 → 原持有者松手 → 对方独立持有；道具始终是同一件，只交接一次。拥抱、扑近、摸头：明确距离起步 → 靠近 → 指定部位接触 → 双方可见的反作用 → 保持或分开。
避免：写成"拿开刀，武器自己掉了"；只写"剑飙射而出"没有握持、解锁、接触结果（成功版也用"飙射"，关键是这三项）；只写"递给她"；物体复制、消失、换款。

**C08 力与反应方向一致｜待判断｜低到中[单次＋类比，待测]**
写法：力的方向、受力者位移、反应方向、尘土方向一致，方向用画面坐标；位移写成整个身体的结果（脚、膝、髋、肩、头依次跟随），强度与冲击匹配（轻接触手腕微沉，重接触整体后撤）。例：蓝方整个身体向画面右侧滑退一步，脚下尘土拖成向右的尘痕。
避免：只写尘土不写身体位移；环绕镜头里用"向前、向后"。

**C03 下坠方向的可见证据｜待判断｜中[重复]**
写法：不只写"疾坠"，写看得见的证据：衣发被气流向上拉起；竖直的岩壁入画；身后留下连续的破坏带。
避免：只写方向的名字（疾坠、下摇）；成功版里对攻有时靠岩壁上的爆点被看见，人物反而被运动模糊压住。

**C40 材质进入动作因果｜通用｜中低[Chibi 记录；单次]**
写法：把材质和重量写进动作：脚踩进松软沙 → 沙下陷留脚印 → 失衡时手掌触沙 → 身体落下 → 停住后痕迹仍在；小体型角色写重量与尺寸的结果（抱起大拖鞋时身体后仰）。
避免：只写"在沙滩上跌倒""拿着大拖鞋"；只验证了可见的踩踏与接触反馈，没验证精确尺寸比例。
