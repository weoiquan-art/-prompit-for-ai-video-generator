# T9 场戏与整片编排
条目：编号 名称｜适用范围｜把握[证据]；写法；避免。图例与编号索引：[evidence/README](../evidence/README.md)。

**O22 场戏与整片编排｜通用｜中[旧·确认]**
写法：完整短剧先定阶段：只有 idea 先交故事层（JIN Story Development），已有获批剧情直接承接并只提取最小交接（当前故事单位、行动原因与目标、阻碍／选择／后果、事件先后、必要对白、入口与出口、不能改变的事实、目标时长、未决项），已有分镜或成片从当前阶段继续。整片先写：开头第一眼看什么、为什么从这里进入；哪些已批准信息现在给、哪些延后；结尾怎样回应前面；再分场——每场写作用、可见事件、观众新得到什么、入口与出口、策划时长，说明相邻场为什么接在一起，核对各场之和与目标总长，内容不足就报告容量，不用空镜或新增剧情填满。"平和—起伏—平和"只是可选的节奏，不是固定三段。编号：场 S01、镜 S01-01、生成单元 G01。
一场戏先答：开始与结束时人物、关系、信息有什么变化，观众依次要看懂什么，哪个可见事件让下一镜成为必要；镜头按职能选（关系、事件、反应、细节、过渡），删掉某镜信息不变就合并；每次切镜写清触发点、下一镜接收的状态、注意力落点；一镜到底也有内部阶段。生成单元：同地点同时间、动作或对白连续推进且连续收益大于整段重做成本时一次生成；换地点或时间、某次揭示需单独精确控制、高复杂动作挤压对白时拆开；生成区间从该单元 0 起算，不混入整片分钟数；生成时长与最终使用长度可以不同。先列全片复用资产，再为每个单元选要上传的子集；资产未就绪的单元标"规划草案"，不阻止全片规划。实际片段齐备后按真实片长验收：人物为何行动、揭示是否过早或遗漏、静默是否仍有作用、跨段方向与道具状态是否连续、音桥起止是否明确；问题交 T8。读故事层或 Canon 用已连接的 GitHub 读取工具，网页抓取失败不等于文件不存在；工具确实不可用就如实说明，先完成能做的 brief。
避免：为凑时长新增剧情或空镜；把每个时间段都计成一次切镜；把计划中的无缝衔接说成已验证；以为模块代表要启动多个 Agent（它们只是职责）；为迁就错误成片改写获批剧情。
