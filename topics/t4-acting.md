# T4 表演、视线与声音
条目：编号 名称｜适用范围｜把握[证据]；写法；避免。图例与编号索引：[evidence/README](../evidence/README.md)。

**C22·C26·C30 表演与视线｜通用｜中低[平台指南＋单次；第三方指南]**
写法：情绪写成可见的身体信号（眼、呼吸、嘴、手、姿态、视线，两到四个够一次变化），按"触发 → 即时反应 → 渐变 → 保持"；微节拍写成"先……短暂停顿……再……"，语气给一个比喻（像刚完成一次科学实验验证）；表情写成状态词加一个小动作（"疑惑、疲惫""轻微皱眉"）；每个表演节拍绑定对应台词。说出每个角色在看什么，视线目标可在画外；先眼后头，眼睛先到目标，头稍后，身体可仍保持原方向。例：听到"挺好的"，男主的视线停了一拍，握手机的手松了，他保持这个表情没有看镜头。
避免：只写"难过""尴尬""认真"；一次写太多面部细节（脸不稳或成了夸张默剧）；写四个情绪阶段却不说哪句台词对应哪一阶段；一次变化拉长到整段；眼头肩手同时机械启动。

**O16 表演的可见通道与惯性｜通用｜中低[旧·实操；旧·确认]**
写法：先问角色此刻想完成什么，行为先于情绪标签：本来继续走，异常声出现后脚步慢半拍、手停住、眼睛先落向声音来源，再靠近处理。通道：眼球落点与扫视、眨眼、呼吸、嘴与下颌、头、肩、手指、重心、动作速度；近景越紧越少用夸张面部；背影或侧背影改用头肩、呼吸、手、脊背、重心。给角色一件真实在做的事（整理耳机、擦杯子），被打断的动作本身就是标点。强刺激、疲劳、疼痛、紧张不因剪辑归零，直到有可见事件改变；多人反应不默认整齐（一个先反应、一个稍晚、一个较弱）。
避免：刺激结束后才突然切表情；眼睛冻结、没有视线转移和眨眼；强事件后立刻回中性；整镜只有一种节奏；停顿里什么都没发生；背影镜头强写正脸。

**C20·C29 声音与对白｜通用｜中低[平台指南＋单次；声音无法从截图验证]**
写法：每个声音提示挂在对应的动作或时间点上，音乐写明上升、保持还是解决；对白写成"角色（条件）：“台词”"，如 母亲（电话）：“儿子，最近怎么样？”；每个角色绑定一段音色参考音频；非中文台词标语言，台词短到适合时长，语气写在台词之前。先继承获批对白；声音可跨镜（写清旧镜延续或新镜提前进入的起止），不借声音新增剧情。
避免：把声音写成没有时间的单独一段；只写台词不指定谁说、什么条件；把"无对白""无音乐""无声音"混为一谈；音色参考的实际效果不知道，2.0 上的效果未知。
