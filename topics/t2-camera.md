# T2 镜头与运镜
条目：编号 名称｜适用范围｜把握[证据]；写法；避免。图例与编号索引：[evidence/README](../evidence/README.md)。

**C38 构图变化先定一个执行者｜通用｜中[Chibi 记录；旧·确认]**
写法：每个阶段先写明谁造成景别、角度或位置的变化：摄影机移动、角色移动或 POV 身体移动，只设一个主要原因。摄影机环绕用连续的角色相对路径点（右侧脚部 → 正面膝以上 → 左前方脸部 → 后方高处 → 拉远全身）；摄影机固定而角色靠近，写"画面大小变化只由角色靠近产生"；第一人称要有可见证明（POV 手或腿入画、递接摸头、角色看向镜头）；要看蹲下就写站立高度 → 身体下降 → 低位停稳，第一帧已在低位就直接写低位。
避免：只写"电影感跟拍""强制环绕轨迹"；摄影机固定又写无动机缩放；两条步数指令互相竞争（"向前走两步"与"步伐不停"，成片一直走）。

**C04 镜头锁定观察目标｜通用｜中低[单次]**
写法：每次镜头运动有一个要看的东西，并给引导线。例：近景绕至乱雪右侧后，荷兰角，剑身作引导线，拉长焦段聚焦宿妄；落点锁定在接触处。
避免：只写镜头动作不写它要看什么；每版只有一个结果，分不开随机性。

**C28 主观视角与反打｜通用｜中[单次]**
写法：写"镜头模拟某人的主观视角"，再用机位高低表达关系，对方看向镜头。例：模拟男主主观视角，低机位仰拍外星人甲，甲直视镜头；模拟甲主观视角，稍高机位俯拍男主，男主抬头看向镜头。
避免：只写"主观视角"不写谁在看、机位高低；这是镜头级视角切换，不是 JIN 自己的第一人称。

**C41 质感词与摄影机身份词分别保留｜待判断｜中[Chibi 记录]**
写法：把"真实手机实拍风格"（媒介与质感）和"第一人称 POV 手持手机拍摄"（摄影机身份与运动）分别写出，沿用已验证原句。
避免：改写成"人的双眼 POV""裸眼视角"，或只剩抽象的"第一人称"（会改变摄影机载体）；这是 Q 版系列的经验，来自一次实际生成。

**C34 镜头术语｜通用｜中[研究报告＋第三方指南]**
写法：常见景别、运镜词直接写（大远景、中景、特写、推进、环绕、后拉）；小众术语保留名称，同时写出观众看到的画面变化（移焦：焦点从前景的手转到背景的人）。
避免：只写小众术语不写画面效果。注意：官方指南和 Melies 都有这一条；一个镜头只用一个主运镜是多个第三方的共识，官方没有明说。

**O09 机位与运动词汇（乱雪）｜待判断｜低[单次；外部作者案例复盘]**
写法：机位词：斜向仰拍、仰拍、俯拍、后仰拍、荷兰角、越肩、地面蝼蚁视角；运动词：快速后退、短促急推、下摇、绕至、横甩、后拉、快切；每个词配一个观察任务（斜向仰拍快速后退 → 下坠与背景反向流动；地面蝼蚁视角置右足前 → 落幅人物、武器、远海同框）。
避免：把词表当配方；没有观察任务的运动词；没看到成片，只有复盘文字。
