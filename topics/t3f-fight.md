# T3f 打斗编排（打斗专用）
条目：编号 名称｜适用范围｜把握[证据]；写法；避免。图例与编号索引：[evidence/README](../evidence/README.md)。接触、受力、脱手见 [T3](t3-action.md)；密度见 [T7](t7-pacing.md)。

**O14 攻防编排｜打斗专用｜中[旧·确认，JIN 2026-10-01]**
写法：先写双方本轮要什么、什么阻碍，再按链写：当前条件 → 发起行动 → 对方响应 → 接触或落空 → 改变后的条件（距离、朝向、支撑、路线、武器状态、防守缺口）→ 下一次行动依据；后续动作利用或应对上一轮结果；保留双方主动性。画面证据：方向与速度用位移、背景相对运动、衣物响应；接触受力用接触点、道具弯曲绷紧、支撑脚变化；冲击后果沿受力方向传播。先后、重叠、延续、同步分别写清，切镜后惯性、碎屑、摆动仍在继续。高速段保留双方方向和响应关系，关键接触给足可见时间，不默认慢动作或特写；速度用速度词（短促、猛烈、一瞬），升格只放关键接触；对峙前视线锁定，距离写成"约三步"。红蓝 v1／v2 无速度词时很慢，v3 加了速度词后没再被指出慢，但同时改了多项。动作链：机位与构图 → 当前实体状态 → 方向性动作 → 接触点 → 受力或特效传播 → 环境结果 → 下一状态。
避免：把对手写成等待接招的道具；无原因重置位置；只写"猛攻、格挡、击飞"；把"建立—展示—反制—大破坏—英雄落幅"当固定套餐；普通碰撞自动加爆炸。

**C06·C07 打斗节奏｜打斗专用｜中[单次]**
写法：每一段展示不同的东西（链剑展开、方印对腿、链刃缠腰、蓄力拳、远海轰飞）；长状态里写阶段变化，并以一次明确的结果事件收尾（回拉、蓄力、击中、轰飞）。
避免：整段是同一套近身动作反复（贴杆、侧身、回剑、追斩……，第 6 次这类词 33 次，成功版 2 次，词频只是代理指标）；同一个接触状态持续多秒（"枪顶摩崖压制段 5 秒"，成片是乱雪被一直捅着沿崖往下）。

**C17 站姿回落｜待判断｜低[单次]**
写法：每一段都给可见的动作动词。
避免：当前段动作写不牢，人物会退回设定图式站姿（双臂张开）；2 秒内连切多个镜头再加冲击帧（推测与此有关）。

**O15 展示任务与强弱｜打斗专用｜低[旧·候选；单案例]**
写法：先定每个时间段主要给观众看什么，再排镜头：空间关系 → 主角能力或武器 → 对手武器或力量 → 威胁逼近 → 招架并留下结束状态（0–15 秒案例）；相邻两次新破坏之间可尝试留一段低强度段。
避免：从单案例推所有打斗同一顺序、同一秒数；把持续余波算成第二次新破坏；低强度不等于复原；故事需要连续升级时可不用。

**O24 打斗功能表与接收｜打斗专用｜中[旧·确认，JIN 2026-09-30 功能复盘]**
写法：对抗缺目的、结果，或决定故事读法的空间条件时才用。目的与结尾都未定时，先只给 3–4 行粗骨架（已说关系、已有交锋、已说后果、开放收尾），不预设谁赢；两项确认后再展开功能表，四列：策划秒数（非提示词时间戳）｜这一段的功能｜强度（高／中／低）｜场景变化（无，或"谁触发 → 变成什么 → 保留／复原"）。按功能起草，不按动作数量，不设默认招数或每秒出手次数；强度看冲击与威胁感，慢动作不等于低强度。场景变化只用已有场景实体；改变可触碰距离、到达路线、胜负或结尾的变化须确认；复原须有已确认依据。提问优先级：目的与结尾 > 节奏曲线 > 场景变化清单 > 招式提醒。
避免：为填表补剧情、人物、能力、结局；把功能段当成镜头或一次生成；把"完整表"当成完整提示词；未授权动手时擅自加攻击或破坏。
