# T8 排查与复盘
条目：编号 名称｜适用范围｜把握[证据]；写法；避免。图例与编号索引：[evidence/README](../evidence/README.md)。

**O20 成片复查｜通用｜中[旧·确认，JIN 2026-09-29／30]**
写法：先收齐可核对输入（实际提交的完整提示词、参考文件与图号顺序、关键帧、模型时长比例设置、成片）；缺原提示词或实际参考，就不能断言"哪句话导致了它"。逐段记"期望 → 实际"，先记已经对的部分。每个关键节拍按"实际原句／图号 → 成片可见事实 → 推定执行单元"记录（主体、状态、方向、接触点、受力、环境结果、摄影机任务），标直接证据／合理假设／无法判断。导演层完成度（中心事件、空间、镜头任务、状态变化）与逐项忠实度（逐招顺序、次数、帧数）分开验收；只确认持续对攻时写"密度成立，次数未核验"。沿"原参考 → 视频资产 → 实际提交 → 成片"找最早偏差，分清资产错、提示词错或矛盾、输入对而成片偏、平台限制；下一轮只改一个变量。规则变更只提候选，JIN 同意才写入。
避免：先套现有规则再反推成片；把计划稿或事后改写当作实际提交；用单次成片证明某个词是唯一原因；资产已错还怪提示词；Q 版身份、实体感、声音另核 chibi- 仓库，Sera 身份与家乡只以 sera-universal 为准。

**O21 生成前预检｜通用｜中[旧·确认]**
写法：只选本任务最可能崩的 3–6 条：参考互相冲突；图中高辨识度细节与文字相反；残留上一镜的角色、道具、场景；第一帧变成无人空镜或必要人物延迟出现；提前执行下一镜动作；术语被误读成别的物体或伤势；背影镜头被强写正脸；左右、朝向、视线矛盾；运镜、人物、环境同时争抢变化；关键空间规则埋在形容词里。缺空间信息先补正向安排（见 T1b），不先堆否定词。提示词太长先删不参与画面的内容，再考虑加限制；人物像木偶回 [T4](t4-acting.md) 补行为。
避免：用长篇否定词与错误图片对抗（先修资产）。

**C25 一次只改一层来排查｜通用｜中低[平台指南]**
写法：生成不对时按顺序一次只改一层：先参考和身份，再镜头结构，再相机，最后风格和音频；下一轮只改一个变量，并写下应出现的可见验收结果。
避免：一次重写所有内容（分不清是哪条指令）；这个顺序是不是最优没有测。

**C18 镜头层稳，动作因果层脆｜待判断｜中[重复]**
写法：写作精力优先放在动作的因果、方向、连接上，而不是只堆镜头词。
避免：当成规则（只来自少数案例）；也可能只是镜头词更容易被理解，或动作错误更容易被我们看出来。
