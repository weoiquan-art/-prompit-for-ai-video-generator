# 统一视频提示词输出模板

采用 LibTV 式三层结构。以下方框内文字是可复制骨架；说明和未使用的占位行不进入正式 Prompt。单镜保留一张镜头卡，多镜按实际数量复制；不固定句数，不为填字段新增事件。

每个生成单元独立交付。导演理由、整片时间位置、资产待办和规划状态写在复制区外；本次生成规格、真实素材绑定与可见执行指令写在区内。纯文字生成时写“本次无参考素材”，不虚构图号。资产未验收的版本在区外明确标“规划草案，尚不可直接提交”。

```text
【本次生成】
片段编号：〔G编号〕。〔模型／版本、画幅、本次生成时长；仅填写已知条件〕。

【参考素材职责】
〔实际角色引用〕：〔对应角色；负责的脸部／身体／服装等属性〕；〔必要的不继承项〕。
〔实际道具引用〕：〔对应道具、持有者、结构与比例；不同形态是否为同一实体〕。
〔实际场景引用〕：〔无人场景的地点结构、地标、材质和基础光线；是否继承原构图〕。
〔实际关键帧／站位／故事板引用，按需〕：用于〔具体镜号与构图／起始状态〕；身份以〔实际身份参考〕为准。
〔实际音频引用，按需〕：用于〔说话人的音色／说话方式〕，对白内容以下方逐字台词为准。
〔同一属性有冲突时，明确对应参考的优先级；没有冲突不重复列规则〕。

【全局要求】
视觉风格：〔整体媒介、角色与环境呈现；必要的色彩、光源、材质与成像结果〕。
空间与连续性：〔本单元共享地点、时间、行动方向及进入状态；仅保留会影响本段的事实〕。
声音与字幕：〔音乐、对白、环境声、字幕权限；继承用户已确定要求〕。
必要限制：〔只保护本次最脆弱的身份、数量、道具形态、空间或事件边界；无须时省略〕。

【分镜拆解】
镜〔全片唯一镜号〕｜〔本次生成内的预计时长或局部时间区间〕｜〔景别〕｜〔机位·拍法〕
画面：〔第一可见帧的构图与角色状态〕。〔沿时间写人物行动／表演、对方或道具响应、镜头与必要环境反馈〕。〔结束状态及仍在延续的运动〕。
台词／声音：〔说话人、语气、逐字台词与必要口型要求；或无对白＋具体环境／动作声〕。
出片要点：〔本镜最不能丢的 1–3 个可见结果；按需含向下一镜交出的状态或不得提前发生的事件，不重复正文〕。

〔有切镜时明确“切至镜……”；同一镜内可用阶段标题或局部区间组织过程，不把每阶段写成切镜。按实际需要继续下一镜。〕
```

参考标签使用当前平台真实支持且已绑定的格式。用户给的 {{角色_key}} 可作为规划占位符；实际提交前核对绑定，换平台时按实际引用方式转换，不假设所有平台都支持同一种标签。

人物年龄、身高、武器尺寸、音色或焦段仅在已知且有作用时使用；普通道具不自动要求独立图。关键帧不是必需项，模板列出它不构成新增资产要求。总时长和局部区间保持一致；精确帧数与出手次数另按是否需要逐项验收决定。

“画面”内部允许充分的连续描述。人物、道具、镜头和环境共同证明同一事件时保留必要细节；动作、情绪与声音各按当前任务密度编写，不复制案例的角色、武器、风格、招式或段落顺序。
