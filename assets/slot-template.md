# 逐段固定槽位模板（默认输出格式）
状态：JIN 指定为默认。把握：低；待测。成功样本（偷骨头、偷薯条、红蓝第三版、作者原提示词）都带此头部，没有对照；每条只生成 1 次，角色、场景、故事难度都不同，不能把成功归因于模板。没看到成片，只有 JIN 的描述。来源与测试记录：[slot-template-evidence](../evidence/slot-template-evidence.md)；作者原文：[author-prompt-guwu-crow](../evidence/author-prompt-guwu-crow.md)。其他成功格式也存在，经验不绑定本格式；旧格式见 [clean-template](clean-template.md)。

〔〕为待填位置，填完删掉〔〕；头部直接写出的值（8K、60fps、50mm、全局限制）是作者自带的默认值，保留并标待测，作用没测过，JIN 指定时可整行省略或替换；不适用的字段整行删除，适用但 JIN 没给的维度见用法第一条。不额外加 IMAX、masterpiece 等质量词（头部默认值除外）。复制区内只写可见执行；导演理由、证据等级、规划状态、资产待办放复制区外。

```text
【分辨率】8K超高清电影级画质
【摄影机+胶片/质感】〔本片的画面质感与拍摄方式〕
【镜头】50mm中焦定焦镜头，1/2.8浅景深
【技术标准】60fps院线标准帧率，〔画幅，如16:9宽银幕画幅〕，〔总时长〕秒时长
【全局限制】全程无超帧、无画面畸变、无多余空镜、无穿帮；〔台词与字幕：全程无台词无字幕／有台词〕
【真人专属补充】〔仅真人片保留；非真人片整行删除〕
【漫剧专属补充】〔仅漫剧／动画片保留：风格名，场景气质，人物造型，光影，色彩，动态要求；非漫剧整行删除〕
【人物/物品设定】参考图1：〔角色〕；参考图2：〔角色〕；参考图3：〔物件〕

分镜时序与运镜(逐秒精准控制)

镜头〔N〕｜〔起〕-〔止〕秒: 〔运镜〕，〔景别〕，〔地点/场景〕，〔主体：角色与角色／角色与物件／角色的某个身体部位〕，〔画面位置〕，出镜人物：〔本段所有出镜的角色〕，〔无台词／角色名台词：「…」〕，〔表情：状态，或从A转为B〕，〔画面动作：谁做什么，带物理反馈〕，限制条件：〔本段必须保证的可见事实，2–3条〕

〔重复上面这一行，直到总时长；每段的起止首尾相接〕
```

用法（均为 [待测]，来自成功样本的写法）：
- [JIN 经验] 头部和风格行定下模型自己选不了的维度（风格、色板、材质、光向、镜头、画幅、帧率、时长）；适用但 JIN 没给的维度，先替他定一个值并说明，不整行删除，不适用的行才删。
- [JIN 经验] 复制区里不留选项、占位和说明，每个字段只写一个值：模型不会从备选里选。【镜头】只写一个焦段，要换就直接替换；原模板的"默认:""备选:"字样和（已替换……）注释是给人看的，作者原提示词留着它们也成功过一次，所以去掉是 JIN 的判断，没有对照测过。
- 每段一个事件；限制条件写本段必须保证的可见事实，也可写"不得提前发生的后续事件"。
- 每段标"镜头N｜起-止秒"（如"镜头1｜0-2秒"），2.0 可省略秒数；区间是内容分配，不等于逐秒服从（标题里的"逐秒精准控制"是作者原话）。
- 台词也可用 {台词}，符号写法见 [T4](../topics/t4-acting.md)。
- 【人物/物品设定】逐张写提供什么、不采用什么、冲突听谁（见 T5）；不想让谁入画，出镜人物只列入画的，限制条件写明没有谁入画。
- 第一人称换位置，写转向方向、空间关系、步数；打斗不用固定正侧面全身构图和灰色背景，速度用速度词（见 T3f）。
