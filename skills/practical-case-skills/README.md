# Practical Case Skills

这里保留用户提供的 3 份 **Higgsfield / Seedance 实操型 Skill** 的独立分支，用作长期可回看的实践证据与方法来源：

- `cinedance-v4/`：视频导演、空间 blocking、第一帧、镜头、物理、灯光、参考控制；
- `lira/`：生图 Prompt 路由、资产生产、镜头锚点、紧凑 Prompt、局部编辑；
- `acting-system/`：角色表演、行为目标、反应、eye life、动作状态与表演连续性。

这些分支的定位与“贤者实操案例”相同：它们是已经用于实际生产的工作方法，不把它们当成纯理论或概念提案。

## 使用方式

1. 需要研究原方法时，先读取对应分支；
2. 分支中的平台特定做法可以继续保留，不要求 JIN 主 Skill 全盘照搬；
3. JIN 主 Skill 只吸收与现有流程兼容、能提高稳定性的部分；
4. 外部 Skill 与 JIN 已验证经验冲突时，不覆盖旧经验，保留差异后再通过实际生成结果判断；
5. 这三个分支继续作为独立实践来源存在，即使其中部分方法已经被吸收到 JIN 主 Skill。
