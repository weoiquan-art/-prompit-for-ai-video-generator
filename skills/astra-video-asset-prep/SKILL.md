# Astra Video Asset Prep

这个 Skill **不负责写最终视频生成提示词**。

它只负责一件事：

> **把视频导演已经确定的镜头需求，翻译成 Astra 能执行的专业资产准备任务。**

最终视频提示词仍由视频导演 AI 负责。Astra 在这里是资产制作 / 预演助手，不替代导演。

---

## 什么时候调用本 Skill

### 调用前门槛（硬规则）

本 Skill 不是看到“动作”“多人”“接触”就自动调用。只有 asset-director 已指出一个清楚的控制问题，或用户明确要求 Astra／分镜／白膜／动作参考时才进入。

进入前必须能回答：

- 哪个核心结果仅靠现有资产与文字难以成立；
- 准备哪一种载体能够直接解决该问题；
- 目标平台或实际制作流程如何使用这份载体。

若答案只是“可能更稳”“动作比较多”或“流程更完整”，立即返回视频导演，用 Prompt 描述动作，不生成资产任务书。普通日常动作、简单 POV、普通生活场景与普通道具一律不因存在于镜头中而升级为 Astra 资产。

当视频镜头仅靠文字很容易让模型猜错时，进入本 Skill。

典型情况包括：

- 角色位置、前后关系、朝向容易漂移；
- 多角色空间关系复杂；
- 镜头角度、景别、人物占比必须稳定；
- 动作包含明显重心变化、躲闪、翻滚、跃起、落地、格挡、摔倒或复杂多人接触等高难度身体动作；普通拿取、递交、指向、开门、行走、跑动、拥抱或简单接触不因此升级为高难度；
- 动作需要学习真人演员 / 动作捕捉参考；
- 连续镜头需要保持运动方向、角色位置和空间连续性；
- 特殊技能、武器或 VFX 仅用文字不容易稳定表达；
- 正式视频生成成本高，希望先用低成本资产验证镜头。

简单日常动作如果现有角色图 + 清楚文字已经足够，不为了流程完整强制增加 Blender 或动作捕捉。

## 本 Skill 与其他模块的职责边界

### 视频导演 AI
负责：

- 决定这条视频发生什么；
- 拆每个镜头的主要展示任务；
- 决定景别、机位、动作过程和结束状态；
- 判断哪个部分最可能生成失败；
- 根据最终资产写正式视频提示词。

### Astra
负责：

- 根据本 Skill 输出的任务书准备所需资产；
- 生成 / 辅助制作分镜；
- 搭建 Blender 白膜 / blocking / previs；
- 准备动作参考、演员动作学习方案或可视化动作载体；
- 按需准备场景、道具、VFX 等参考资产。

### 最终视频模型
负责：

- 在角色资产、分镜 / 白膜 / 动作参考和文字导演要求基础上生成最终成片。

不要把 Astra 的资产任务说明直接当成最终视频提示词。

---

## 资产载体：先判断“难在哪里”

先找当前镜头最难稳定的部分，再决定资产类型。

### A. 16:9 线稿分镜资产

适合锁定：

- 这一镜主要看什么；
- 人物在画面哪里；
- 景别与水平 / 纵向角度；
- 大致姿势；
- 前景 / 中景 / 后景；
- 事件前后顺序；
- 起幅 / 落幅构图。

默认形式：

- 16:9 横构图；
- 线条绘画 / storyboard / key pose 草图；
- 可少量灰阶或色块辅助阅读；
- 不追求最终插画质量。

人物资产负责锁“她是谁”；分镜资产负责锁“这一镜看什么”。

每张分镜只服务它对应的镜头，不自动让整条视频继承同一构图。

### B. Blender 白膜 / Previs

适合锁定：

- 大世界空间关系；
- 摄影机位置与朝向；
- 景别和人物占画面比例；
- 角色之间的距离；
- 角色在前 / 中 / 后景的位置；
- 身体朝向；
- 大姿势 / key pose；
- 行走、转身、靠近、绕行等 blocking；
- 连续镜头中的方向和位置稳定。

白膜的职责不是做“低配成片”，而是提供**三维空间与表演骨架**。

白膜阶段允许：

- 简单几何场景；
- 灰白材质；
- 角色代理模型；
- 简化道具；
- 基础相机；
- blocking 级动画；
- viewport / playblast 预览。

不优先做：

- 精细脸模；
- 发丝；
- 高级材质；
- 最终灯光；
- 成片级渲染。

### C. 动作参考 / 演员 / Mocap 学习载体

适合锁定：

- 发力顺序；
- 重心移动；
- 肩、胯、腰的联动；
- 四肢轨迹；
- 动作速度与停顿；
- 接触前、接触瞬间、接触后的身体反馈；
- 高难度动作真实的身体力学过程。

可以使用：

- 真人演员动作参考；
- 动作捕捉；
- 简单代理角色动画；
- 分阶段 key pose；
- 已有可靠动作视频。

这里的核心不是让最终角色“长得像演员”，而是让最终角色**学习演员的动作过程**。

### D. 独特 VFX / 武器 / 道具资产

当文字难以稳定表达形状、结构、颜色关系、运动轨迹或连接方式时，再增加对应视觉资产。

不要因为有特效就机械增加资产；只有文字无法承担时才补。

---

## 高难度动作的组合思路

遇到复杂动作时，不要求单一资产解决所有问题。

可以把不同问题拆给不同载体：

```text
角色身份资产
→ 锁“她是谁”

16:9 分镜
→ 锁“这一镜看什么”

Blender 白膜
→ 锁“她在哪里、镜头在哪里、大姿势是什么”

动作演员 / Mocap / 动作参考
→ 锁“身体具体怎么动”

VFX / 武器资产
→ 锁“特殊视觉元素长什么样”

视频提示词
→ 把所有资产职责与时间过程组织成最终导演指令
```

例如高难度闪避镜头：

- Blender 白膜先确定角色在画面左侧、对手在右后方、低机位、身体侧转、重心压低；
- 动作参考再说明肩膀后撤 → 腰转 → 重心移到后脚 → 前脚滑开 → 手臂回收；
- 角色身份资产继续锁定最终角色外观；
- 视频导演 AI 最后把这些内容写进对应时间段。

## Astra 任务书生成流程

### 1. 先读取导演意图

至少确认：

- 视频时长；
- 当前镜头数；
- 每镜主要展示任务；
- 当前已有角色 / 场景 / 道具资产；
- 哪个动作或空间关系最难；
- 最终希望 Astra 交付什么。

用户表达还没完整时，只问**会改变资产方案的关键缺口**，不要自己补剧情。

### 2. 判断需要哪种载体

只选择真正有用的资产：

- 线稿分镜；
- Blender 白膜；
- 动作 / Mocap 参考；
- VFX / 道具；
- 或以上组合。

### 3. 为 Astra 写“执行级”任务

不要只说：

> 做一个专业 Blender 预演。

要明确：

- 场景中有哪些对象；
- 人物位置；
- 角色朝向；
- 相机位置 / 景别；
- 每个时间段发生什么；
- 哪些大姿势必须出现；
- 哪些东西只用代理即可；
- 什么不需要精修；
- 最终要交付什么文件 / 截图 / 预览。

### 4. 资产回来后先验收，再写最终视频 Prompt

检查：

- 角色位置是否正确；
- 镜头角度是否符合导演意图；
- 大姿势是否清楚；
- 动作参考是否覆盖真正困难的部分；
- 资产职责有没有互相冲突；
- 是否存在无关信息污染最终生成。

不合格就只修改对应资产，不先重写整个视频提示词。

## Blender 白膜 Astra 提示词模板

```text
你现在不是制作最终成片，而是在 Blender 中制作一份用于 AI 视频生成前验证的白膜 / blocking / previs。

【项目目标】
[视频 / 镜头目标]

【本次白膜必须锁定】
- 大世界空间关系：...
- 角色位置：...
- 角色朝向：...
- 大姿势 / key pose：...
- 摄影机位置与景别：...
- 前景 / 中景 / 后景：...
- 角色移动路径：...
- 连续镜头方向：...

【场景白膜】
只搭建动作成立所需的大结构：
- ...
- ...

使用简单几何体和灰白材质，不做最终美术细节。

【角色代理】
角色只需要保持用于判断姿势和镜头的身体比例及必要轮廓。
需要保留的识别轮廓：...
不需要精修：脸部、发丝、材质、贴图、最终服装细节。

【镜头 / 时间轴】
镜头1｜[时间]
主要展示任务：...
Blocking：...
相机：...
结束状态：...

镜头2｜[时间]
...

【动作关键姿势】
1. ...
2. ...
3. ...

【交付】
- Blender 白膜场景；
- 每镜关键帧截图；
- viewport / playblast 预览；
- 相机清楚命名；
- 如无法直接交付 Blender 文件，输出可执行的场景 / 相机 / blocking 制作清单。

【不要优先制作】
最终材质、精细脸部、发丝、复杂灯光、最终渲染。

本次唯一目标：先验证空间、机位、角色位置、大姿势和动作 blocking 是否成立。
```

## 动作演员 / Mocap Astra 提示词模板

```text
你现在需要为一个 AI 视频镜头准备“动作学习资产”，不是最终角色画面。

【动作目标】
[用一句话说明动作]

【角色起始状态】
- 身体朝向：...
- 重心：...
- 双脚位置：...
- 双手状态：...
- 视线：...

【动作过程必须拆清楚】
1. 发力前身体信号：...
2. 第一阶段：...
3. 重心转移：...
4. 关键接触 / 腾空 / 转向：...
5. 反作用 / 缓冲：...
6. 最终稳定姿势：...

【重点学习】
- 肩胯关系：...
- 腰部旋转：...
- 四肢轨迹：...
- 速度变化：...
- 停顿：...
- 接触反馈：...

【表现要求】
动作必须具有真实身体力学，不要只从起始姿势直接跳到结果姿势。

【交付】
优先给出：
- 可观察完整身体动作的视频 / 动作捕捉结果；
- 或 4–8 个关键动作姿势；
- 或可用于 Blender 代理角色的 blocking / animation 数据。

演员 / 代理只负责动作，不负责最终角色身份与外观。
```

## 默认输出格式

当用户说“帮我叫 Astra 准备这个镜头的资产”时，本 Skill 默认输出：

```text
【为什么需要资产】
一句话说明当前最难控制的问题。

【建议资产】
只列真正需要的载体。

【给 Astra 的完整提示词】
可直接复制执行。

【Astra 应交付】
明确文件 / 图片 / 预览 / 动作参考。

【回来后我会检查】
只列后续写视频 Prompt 前必须确认的几项。
```

不要输出大量方法论解释，优先让用户马上能把任务交给 Astra。

---

## 与最终视频 Prompt 的衔接

资产确认后，回到视频导演流程。

最终视频提示词需要明确说明每份资产的职责，例如：

- 人物设定图：锁角色身份；
- 分镜图：只锁对应镜头构图 / 大姿势；
- Blender 白膜关键帧：锁空间、人物位置、朝向与相机关系；
- 动作参考：只学习身体动作与重心过程，不继承演员身份；
- VFX 图：只锁特殊效果可见结构。

不要让一份参考资产无边界地控制整条视频。

---

## 治理

- 用户明确的制作流程和资产职责可以直接记录；
- 新案例先作为案例证据，不因为一次成功自动升级为全局规律；
- AI 自己推导出的新规则，必须先向用户提出，获得同意后再写入；
- 不宣传“有白膜 / Mocap 就一定成功”，它们的作用是减少模型猜测、提高可控性；
- Astra 实际可执行能力以当时产品能力为准，若无法直接完成某种文件，则退化为输出可执行制作方案 / blocking / 脚本，而不是假装已经生成。
