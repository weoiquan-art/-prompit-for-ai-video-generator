# Idea Parser

接受一句话、零散画面、情绪、截图或已有剧情，先整理真实意图和本轮交付目标。用户不必先懂编剧、构图和镜头术语。本模块负责理解与找缺口，不自行承担完整剧情、逐招编排或最终提示词。

## 先按规模和材料完成程度分流

| 模式 | 适用输入 | 整理重点 | 下游 |
|---|---|---|---|
| 短片段 | 常见约 15 秒；当前事件、动作或情绪节拍 | 核心事件、入口、过程与落点 | 必要场戏／单镜设计 → 统一 Prompt |
| 完整短剧 | 常见 1–5 分钟；跨场因果或多个片段组成影片 | 人物目标、关键阻碍／选择／后果、事件链与结尾 | 故事开发 → 整片导演安排 → 各场镜头与 Prompt |

时长不是硬阈值。按事件规模处理其他长度；短片段也可有小故事，短剧也可单场。用户只处理长片中的一个镜头时采用片段入口并继承整片上下文。Q版仍按主入口转独立 Skill。

同时记录当前材料是 idea、探索剧情、获批故事、已定分镜还是实际成片。已批准剧情直接交 preproduction，不重新发明或要求再次填写完整 Story Package；已确认空间与迭代保持继承。

## 因果理解

从原话提取“为什么行动 → 要完成什么 → 遇到什么 → 怎样应对 → 改变什么”，仅记录已有项。动机让行为有来由，阻碍、选择与后果帮助发展一场戏；不为每个日常动作强加冲突，不为填字段编心理动机或前史。

需要正式发展或改写剧情时，读 [JIN Story Development](https://github.com/weoiquan-art/JIN-Story-Development/blob/main/SKILL.md) 并沿其流程协作；优先用主入口指定的已连接 GitHub 文件工具读取，不以公开页面／raw 地址失败判断 Skill 缺失。本模块交出 brief，故事层提出与确认剧情。影片“平和—起伏—平和”只记为用户指定的节奏偏好，不自动生成三段故事。

## 从输出需要反查缺口

| 缺口类型 | 处理 |
|---|---|
| 已有事实 | 先查本轮材料、用户纠正与已确认结果，直接继承，不重复问 |
| 导演执行选择 | 机位、构图、观察距离、切镜、节奏分配等由 GPT 提出具体可撤回方案；标必要假设后继续 |
| 重要未决事实 | 身份、核心目标、关键选择、胜负、结局、重要对白或会改变故事读法的空间条件，集中向用户确认 |
| 真实素材缺口 | 区分实际缺文件、未验收与可文字生成；只问阻断当前交付的项，资产判断交原有 asset 流程 |

缺景别、焦段、每镜秒数不自动成为问题。空间距离若决定能否碰到、谁先到达、何时揭示或故事结尾，仍属于重要决定；不能借“执行选择”改故事。用户已委托的范围内直接选择，不反复征求同一项。

每轮最多 3 个关键问题，包含故事、空间、战斗与资产，不各问一轮。说明缺什么及影响哪一步；先问当前阶段最高影响的项，不提前把全片后续细节列成问卷。

## 空间与战斗的专项接收

本节先决定是否进入专项；下列参考的表格与历史示例只服务已选定的具体片段／场戏，不覆盖上面的规模分流与缺口分类。

- 短剧故事未定：先交故事 brief 和必要问题，不逐场画站位图、确定距离或展开招式。
- 具体场戏需要核对关键物理关系：按 [意图保真与空间接收](references/rough-idea-intent-fidelity.md#统一接收确认) 提取来源，用简短合并表与必要示意核对。
- 对抗／打斗缺目的、结果或决定故事读法的空间条件：按 [战斗接收补充](references/intake-understanding-and-spatial-confirmation.md) 提供功能骨架并问关键项。目的与结果都未定时不提前设计胜负。
- 总时长或节奏未给：可按内容容量提出估算／节奏方案；只是制作执行选择时不因此单独停在确认阶段。用户明确要求先确认的范围照办。
- 已确认事项、信息完整任务、诊断、样本学习、资产验收与迭代不重开问卷。

用户明确“直接写／跳过确认”时，说明必要执行假设后继续到授权交付阶段；不把未定故事当获批事实、不声称素材已验收、不自动生成图片或视频。

## 两种 brief

先一句话复述，再按当前模式给正文最多 10 行；表与问题按需附。完成理解所需即可，不为写满十行造信息。

### 短片段

```text
模式／当前交付阶段：
核心事件与目的：
入口状态／上一段承接：
动作或情绪变化：
结尾／交给下一段：
观众必须看清：
时长／画幅／已知平台：
已有素材与必要空间事实：
执行提案／重要未决项：
```

### 完整短剧

```text
模式／当前交付阶段：
一句话 idea 与想要的观众体验：
主角与已有行动原因／目标：
已定阻碍、选择与后果：
已定事件链／场次线索：
开头与结尾已定内容：
目标总长／画幅／已知平台：
已有故事、Canon 与资产资料：
不可改动项／授权探索范围：
重要未决项／交给故事或导演层的下一步：
```

故事已批准且资产与执行条件满足时，主入口继续完成用户要求的最终提示词，不因为 brief 有独立格式就额外停顿。完整短剧交接细节见 [短剧导演流程](../../references/short-drama-direction.md)。
