# Shot Designer

只负责“这一镜怎样被摄影机看见并完整发生”。

## 核心要求

每镜只完成一个主要变化。先写本镜唯一任务，再搭建摄影机与空间。

至少确定：

- 本镜唯一任务；
- 景别；
- 水平角度；
- 纵向角度；
- 摄影机是否移动、怎样移动、为什么移动；
- 前景／中景／后景；
- 起幅；
- 过程；
- 落幅；
- 焦点变化与镜头内不变量（按需）；
- 剪辑出口；
- 本镜不得提前发生的后续关键动作（按需）。

## 设计原则

1. 起幅、过程、落幅必须组成真实状态变化，不要只是三段同义描述。
2. 景别回答“看多少”，水平角度回答“从哪一侧看”，纵向角度回答“从多高/多低看”。
3. 运镜必须跟随动作、视线、遮挡或空间揭示，不要拿运镜替代角色动作。
4. 摄影机移动时，按需要写清空间揭示顺序，例如：前景树叶和山雾 → 亭檐灯笼 → 亭柱栏杆 → 坐姿人物与瀑布。
5. 前景负责距离、遮挡和进入接口；中景承载当前中心事件；后景稳定空间方向与环境反馈。
6. 一个连续镜头若有重要不变量，明确写出，例如摄影机横移时高度始终保持在人物胸口。
7. 落幅必须可以被下一镜继承，不能写成不存在的“抽象结束”。
8. 时长不足时减镜，不压缩所有动作。

## 输出骨架

```text
【本镜唯一任务】

【景别】
【水平角度】
【纵向角度】
【摄影机运动】

【画面结构】
前景：
中景：
后景：

【起幅】
【过程】
【落幅】

【焦点变化 / 镜头内不变量】（按需）
【本镜不得提前发生】（按需）
```

不要在本 Skill 中展开角色微表演、声音或通用负面词库。
