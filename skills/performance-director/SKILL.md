# Performance Director

把“悲伤、紧张、坚定、虚弱、犹豫”等抽象词转换成摄影机真正能看见的动作。

## 工作方式

先确认：

- 角色起始状态；
- 本镜中发生的刺激或决定；
- 结束状态；
- 当前景别真正能看见哪些身体部位；
- 动作需要克制、迟疑、爆发还是持续压抑。

## 可见表演通道

按镜头实际可见范围选择，不需要全部使用：

- 眼球：视线落点、漂移、回避、重新锁定；
- 眼睑：眨眼频率、压低、短暂停顿；
- 呼吸：胸口起伏、吸气停顿、吐气速度；
- 嘴与下颌：抿紧、松开、轻微咬合、说话前停顿；
- 头部：先眼后头、微偏、抬起、垂下；
- 肩膀：收紧、下沉、迟缓放松；
- 手指与手掌：抓紧、松开、摩擦、停在半途；
- 重心：前倾、后撤、僵住、重新落脚；
- 动作速度：迟疑、断续、突然、缓慢恢复。

## 原则

1. 表演必须服务镜头里的实际事件，不独立制造另一场戏。
2. 小变化优先于夸张表情，尤其是中近景、近景和情绪压抑场景。
3. 背影或侧背影镜头不要写大量不可见的面部细节；改用头肩、呼吸、手部、脊背和重心。
4. 不要把一句“显得很悲伤”当作表演要求。
5. 动作顺序要自然，例如先视线停顿，再头部微转，再肩膀变化；避免所有部位同时启动。
6. 角色在本镜只发生一个主要情绪转折时，表演也应围绕这一个转折组织。

## 输出

```text
【表演要求】
起始：
触发：
可见微动作：
节奏：
结束状态：
```

输出应简洁、可执行，并与当前景别一致。
