# Performance Director

本 Skill 的核心不是“让角色演出情绪”，而是：

> **让角色在当前目标与压力下做出可见行为，情绪从行为中自然出现。**

当前方法吸收 `../practical-case-skills/acting-system/SKILL.md` 中已经用于 Seedance 实操的表演经验，同时保留 JIN 原本的微表演控制方式。

## 先确认角色为什么动

写表演前先确认：

- 角色此刻想完成什么；
- 什么刺激、阻碍或新信息改变了她；
- 她现在采用什么具体办法；
- 本镜中有没有明显 beat / 策略变化；
- 角色起始身体状态；
- 结束状态；
- 当前景别真正能看见哪些身体部位；
- 动作需要克制、迟疑、爆发还是持续压抑。

对于单人镜头，目标不一定指向另一个人，也可以指向：

- 一个装置；
- 一个危险；
- 一个需要完成的任务；
- 一个想隐藏的事实；
- 一个想离开的空间。

不要为了套理论强行给每个镜头编复杂心理。

## 行为优先于情绪标签

不要只写：

- 她很紧张；
- 她很愤怒；
- 她很悲伤；
- 她很坚定。

更优先写：

- 她本来继续走，异常声出现后脚步先慢半拍；
- 手上的动作停住；
- 眼睛先落向声音来源；
- 她短暂停一下确认，再直接靠近处理。

“冷静、紧张、愤怒、犹豫”应该从行为结果被观众感受到，而不是靠脸部硬演。

## Beat：变化必须能被看见

Beat 不是单纯时间段，而是角色处理事情的方法发生变化。

当出现以下情况时，可以形成新的 beat：

- 新信息进入；
- 原方法失败；
- 目标达成；
- 权力或距离关系改变；
- 角色做出新的决定。

Beat 变化要通过可见行为落地，例如：

- pause；
- posture change；
- gaze shift；
- 呼吸改变；
- 说话速度改变；
- 手上的动作停止或恢复；
- 重心改变；
- 人物距离改变。

不要为了“有 beat”机械塞很多转折。

## Reaction：角色不是等 cue 才开始演

重要刺激发生时，反应可以在刺激尚未完全结束前开始。

例如：

1. 眼睛先变化；
2. 呼吸或手部先停一下；
3. 身体出现轻微预备；
4. 随后才真正转头、说话或移动。

重要信息出现后允许一个短暂 assessment moment：角色先消化，再决定下一步。

瞬间从中性脸切换成“表演表情”，容易像 AI 木偶。

## Eyes before head

眼睛、头和身体不是同一层动作。

优先使用：

- 眼睛先到目标；
- 头部稍后跟随；
- 身体可能仍保持原方向；
- 肩膀与重心最后才决定是否真正转过去。

不要让眼、头、肩、手和身体机械同步启动。

## Eye Life：避免死眼

重要角色保持自然、持续的眼神生命：

- 有明确 gaze target；
- 有细小扫视与重新落点；
- 眨眼不是固定机械频率；
- 思考时视线可以短暂漂移；
- 受控冷静不是冻结，而是更少、更慢、更有目的的眼动；
- 眼睛通常比头更早抵达新的注意目标。

近景越紧，越应该减少夸张面部动作，让眼睛和思考承担更多表演。

## Business：给角色一个真实正在做的事情

如果场景允许，角色不要只站着“演情绪”。

可以让她同时在做一个真实物理任务，例如：

- 修设备；
- 整理耳机；
- 擦杯子；
- 数钱；
- 收拾东西；
- 检查工具；
- 扣紧护具。

### Interrupted Action

正在进行的动作突然停止，可以成为很强的表演标点。

例如：

```text
Sera 一边走一边调整耳机；异常声出现时，手停在半途，眼神先移向右侧。
```

不需要大表情，事件已经被观众读到。

## 身体状态先于心理解释

按镜头需要控制：

- 重心高 / 低；
- 动作快 / 慢 / 经济；
- 肩膀开放 / 收紧；
- 呼吸高而急 / 低而慢；
- 身体是否占空间；
- 手是否有多余小动作；
- 脚步是否稳定。

角色的身体应该先告诉观众她现在处于什么状态。

## 距离与 Status 也是表演

人物靠近、后退、停在门口、背过去、站起而另一人仍坐着，都可能是 beat 的变化。

但空间位置本身由 `shot-designer` 负责锁；本 Skill 只解释角色为什么改变距离与姿态。

来源 ACTING Skill 记录了“更稳定、更少动作”常可表现高 status，“频繁碎动作”常可表现低 status。JIN 只在当前角色和场景合适时使用，不把它做成固定人格公式。

## 可见表演通道

按镜头实际可见范围选择，不需要全部使用：

- 眼球：视线落点、漂移、回避、重新锁定；
- 眼睑：眨眼频率、压低、短暂停顿；
- 呼吸：胸口起伏、吸气停顿、吐气速度；
- 嘴与下颌：抿紧、松开、轻微咬合、说话前停顿；
- 头部：先眼后头、微偏、抬起、垂下；
- 肩膀：收紧、下沉、迟缓放松；
- 手指与手掌：抓紧、松开、摩擦、停在半途；
- 重心：前倾、后撤、僵住、重新落脚；
- 动作速度：迟疑、断续、突然、缓慢恢复。

## 高难动作：关键状态链优先

对于闪避、翻滚、格挡、抓腕、摔倒、跳跃落地等高难动作，不要在一个短时间块里塞超长细碎过渡。

可以优先设计成：

```text
起始状态
→ 关键动作状态
→ 接触 / 受力状态
→ 落地 / 恢复状态
```

例如：

```text
mid-dodge → attack passes the torso → wrist contact → grounded recovery
```

这是 `states not transitions` 的实操用法。

但简单、自然、模型容易完成的动作仍可直接按连续过程描述，不把所有动作都机械切成 pose 列表。

## 状态惯性

强刺激或情绪变化不会在下一秒自动归零。

如果角色经历：

- 疲劳；
- 疼痛；
- 紧张；
- 尴尬；
- 惊吓；
- 呼吸紊乱；
- 身体受力；

这些状态应继续影响后续 beat / 下一镜，直到有可见理由改变。

## 多角色反应

多人场景不要默认整齐同步。

更自然的是：

- 一个人先反应；
- 第二个人稍晚；
- 第三个人反应较弱、不同，或没有反应。

只有剧情明确需要整齐同步时才这样编排。

## 原则

1. 表演必须服务镜头里的实际事件，不独立制造另一场戏。
2. 行为目标优先于直接展示情绪。
3. 小变化优先于夸张表情，尤其是中近景、近景和情绪压抑场景。
4. 背影或侧背影镜头不要写大量不可见的面部细节；改用头肩、呼吸、手部、脊背和重心。
5. 动作顺序要自然，例如先视线停顿，再头部微转，再肩膀变化；避免所有部位同时启动。
6. 角色在本镜只发生一个主要情绪转折时，表演也应围绕这一转折组织。
7. 表演段落不负责服装、镜头、色彩和灯光；这些交给其他模块。
8. 已经由动作参考 / Mocap / 白膜稳定提供的大动作，不必在表演段重复描述全部骨架；重点补眼神、反应、节奏和细微身体状态。

## 输出

```text
【表演要求】
目标：
阻碍 / 触发：
当前策略 / 行为：
起始身体状态：
反应顺序：
Eye life：
可见微动作：
Beat 变化：（按需）
关键动作状态链：（高难动作按需）
节奏：
结束状态 / 需要继承的状态：
```

输出应简洁、可执行，并与当前景别一致。


## 动作物理可行性推演

当动作涉及边界内外、身体朝向、承重、平衡、移动平台、明显外力、人与物体接触，或抽象动作词可能产生不可能姿势时，读取 [references/physical-plausibility-pass.md](references/physical-plausibility-pass.md)。

先推演空间侧、支撑点、重心、发力与反作用、状态惯性以及当前机位真正可见的身体证据，再把必要结果压缩进【表演要求】。这一步用于回答“真实身体会怎样完成该动作”，不改变用户已经确定的故事，也不自动要求增加姿态图、动作图或其他资产。
