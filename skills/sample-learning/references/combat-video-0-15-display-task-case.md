# 战斗视频案例学习：0–15 秒展示任务拆分

> 状态：用户已确认 0–15 秒成片中的动作与展示没有问题，可以作为学习样本。
>
> 范围限制：只学习本案例 0–15 秒。15 秒之后的内容目前不纳入本记录，也不据此推导规则。

## 样本定位

这次学习重点不是抽象总结“战斗应该怎么写”，而是观察这 15 秒里**每一个时间段到底负责向观众展示什么**。

当前可确认的核心观察：这段视频没有把人物能力、对手力量、攻击逼近和招架结果同时塞在一段里，而是让不同时间段承担不同的主要展示任务。

## 0–3s｜先交代完空间关系

主要任务：**把双方人物与场景空间关系交代清楚。**

观众在这一段先知道：

- 谁处于近处 / 主视角位置；
- 对手在哪里；
- 双方处于怎样的对峙空间；
- 场景整体关系已经建立。

这一段的重点不是马上开始复杂攻击，而是让后续动作有清楚的空间基础。

## 3–6.4s｜展示蓝发人物瞬移与旋转刀

主要任务：**展示蓝发人物的能力与武器。**

这一段依次让观众看到：

- 蓝发人物的瞬移效果；
- 很近的人物展示；
- 旋转刀的动作与视觉效果。

这一段主要服务蓝发人物本身，不急着同时解释对手的力量。

## 6.4–9.1s｜切给对手武器与力量

主要任务：**把注意力交给红发对手，让观众看到她正在准备力量。**

画面重点：

- 对手手臂 / 手部；
- 握住武器的特写；
- 武器上的力量开始被展示。

通过这种切换，观众先看完蓝发人物的能力，再明确知道另一方也已经准备出招。

## 9.1–11.9s｜蓝发背影 + 红发力量逼近

主要任务：**展示威胁正在逼近。**

画面以蓝发人物背影作为稳定主体，同时让红发一方的力量向她逼近。

这一段的重点不是提前完成招架，而是建立：

> 蓝发人物仍在画面中，而攻击已经越来越接近她。

因此真正明确的“准备招架”留到下一段再展示。

## 11.9–15s｜侧颜准备招架 → 过程 → 帅气结束

主要任务：**把蓝发人物的应对与结尾魅力完整展示出来。**

这一段依次表现：

- 蓝发人物侧颜；
- 准备招架；
- 招架过程；
- 交锋完成；
- 最后留下帅气的结束状态。

结尾不是只追求“攻击已经结束”，还要给人物一个清楚、有记忆点的结束展示。

## 本案例当前可学习观察

这 15 秒可以先记录一个案例级观察：

> **不同时间段分别承担不同的主要展示任务。**

本案例实际形成的观看顺序是：

```text
空间关系
→ 主角的能力 / 武器
→ 对手的武器 / 力量
→ 威胁逼近
→ 主角招架并帅气结束
```

它的价值在于：观众每一段都知道当前应该看什么，而不是让所有信息同时竞争注意力。

## 暂不升级为全局规则

目前不要从这一个案例直接推导：

- 所有战斗视频都必须使用相同秒数；
- 所有战斗都必须按这五段顺序；
- 3–6.4 秒一定要展示瞬移；
- 6.4–9.1 秒一定要给手部特写；
- 结尾一定要使用侧颜。

这些都是本案例的具体导演选择。

当前只保留一个已确认的案例经验：**先明确每个时间段主要给观众展示什么，再安排镜头与动作。** 是否升级为更通用的导演规则，等待更多真实样本验证与用户确认。
