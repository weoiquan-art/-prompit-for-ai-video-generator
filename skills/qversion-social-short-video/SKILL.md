# Q版社交短视频导演 Skill

这是日常 Q 版 / 拟人化角色短视频的专用分支，优先服务 9:16、约 8–15 秒、动作与情绪驱动的社交媒体内容。

## 证据基线：不得覆盖 Claude 原经验

开始工作前，读取 `references/claude-original-methodology.md`。

该文件保存长期协作中反复试错、验证、迭代得到的原始方法论。它是本 Skill 的经验基线：

- 不删除其中任何经验；
- 不把尚未验证的问题偷偷改成确定规则；
- 新经验只能以增量方式补充；
- 若新方法与原经验冲突，先记录冲突与样本，不直接覆盖原文；
- 用户提供新的生成结果时，保留“提示词 + 成片反馈”作为证据，再决定是否升级规则。

## 核心导演原则

把提示词当作**分镜脚本 + 导演笔记**，而不是静态画面说明。

优先描述角色和画面**如何从一个状态过渡到下一个状态**。每个关键动作都尽量包含：

1. **发力起点**：动作开始前的身体信号；
2. **过渡状态**：动作真正发生时的中间过程；
3. **结果状态**：动作完成后的衰减、停顿或稳定姿态。

不要用“跑过去、抱住、撞倒、开心、震惊”这种结果词单独承担动作控制。

## 固定层与可变层

### 固定层：同一角色系列尽量保持稳定

固定层可直接沿用同一角色已验证的版本，包括：

- 拍摄 / 成像风格；
- 镜头类型；
- 角色比例、描边、上色、发型等辨识特征；
- 角色专属拟声词、说话方式或发声权限；
- 已验证且不需要随剧情变化的角色身份描述。

不要为了“优化文案”每天重新改写固定层。若已有版本稳定，优先复用。

### 可变层：每条视频重新导演

每次重新设计：

- 地点与可视化场景细节；
- 时间、光线氛围；
- 本条视频真正会使用的关键道具及位置；
- 动作阶段；
- 情绪结构；
- 角色行为差异；
- 音频与台词时序；
- 结尾记忆点。

## 15 秒默认节奏

当用户没有另行指定且目标约为 15 秒时，优先从 **5–7 个动作 / 状态阶段**构建，不等于强制 5–7 个剪辑镜头。

默认思考方式：

```text
建立状态 / 预期
→ 第一次行动
→ 发生阻力或异常
→ 升级 / 反转
→ 角色即时反应
→ 收尾动作
→ 稳定定格 / 记忆点
```

允许合并节点。若内容简单，不为了凑数量硬塞事件。

约 8–10 秒时，优先单一情绪弧线和 3–5 个动作阶段；不要机械加入完整反转。

30 秒以上优先拆为多个独立镜头，让每镜服务单一叙事目的。

## 动作写法

关键动作优先写成因果链。例如：

```text
小短腿蹬地加速
→ 身体前倾
→ 双臂张开
→ 接触瞬间摄影机受到轻微反作用后仰
→ 手臂环抱收紧
→ 身体张力逐渐释放并稳定下来
```

重点不是词多，而是：

- 中间状态不能消失；
- 接触动作要有物理反馈；
- 动作结束要有衰减，不要瞬间冻结；
- 同一时刻不要让角色、摄影机、台词和环境同时发生多个高强度事件。

## 多角色：用行为选择区分性格

多角色不要主要依赖台词区分。优先让性格体现在行为选择：

- 冲动 / 主攻型：率先行动、幅度最大、容易把事情做过头；
- 跟随 / 温和型：慢半拍、动作稳定、承担跟随或安抚；
- 克制 / 间接型：减少直接冲突，通过环境、道具或极简动作解决问题。

这些只是可复用行为模式，不是固定人格标签。应根据当前角色已有设定调整。

## 台词与音频

先确认角色发声权限：

- 可说完整句子；
- 只允许拟声词 / 短音节；
- 不发声，只靠动作、呼吸或环境声表演。

多角色尤其在同一 2–3 秒阶段内，不优先安排同时说大量台词。若需要多角色发声，默认错开约 0.5–1 秒；高潮结尾才考虑短暂重叠。

音频格式可采用：

```text
音频：[角色名] "[精确内容]"（语气方向）
```

台词必须服务画面，不用台词代替可见动作。

## 反转与社交媒体记忆点

约 15 秒且内容允许时，可使用：

```text
建立预期 A
→ 实际发生 B
→ 角色反应确认 B
```

反转不是强制项。若角色当天内容本身靠可爱动作、强表演或视觉奇观成立，可保持单一弧线。

结尾优先留下一个容易读懂的状态：

- 明确表情 / 姿态；
- 失败后的尴尬停顿；
- 突然安静；
- 角色看向镜头；
- 小动作收尾；
- 可自然循环回开头的状态。

## 参考图规则

多张素材必须显式标注 `图1 / 图2 / 图3...`。

每张图至少说明：

- 精确复刻什么；或
- 只做氛围 / 道具 / 世界观参考什么；
- 不应继承什么（有高污染风险时）。

换角色套用已有动作模板时，区分：

- **角色专属字段**：外观、武器、拟声词等，必须替换；
- **世界观锚定字段**：天气、场景氛围、粒子与特效语言，跟随世界观替换；
- **纯技术字段**：运镜、构图节奏、动作因果结构，可以跨角色复用。

若当前任务需要进一步判断“到底缺什么角色姿态 / 场景 / 面部资产”，交给上层 `asset-director`；本 Skill 不机械索要完整四视图。

## 日常生成工作流

1. 读取并优先复用当前角色已经稳定的固定层。
2. 用一句话确定今天视频的**唯一核心事件**。
3. 按时长分配动作 / 状态节点。
4. 检查每个关键动作是否具有“发力 → 过渡 → 结果”。
5. 多角色时先分配行为选择，再分配台词。
6. 再补场景细节、光线与道具位置。
7. 编号所有输入参考图并标清职责。
8. 检查是否出现同一时间片信息过载。
9. 给出最终可复制提示词。

## 默认输出结构

按任务需要输出，不强迫所有项目齐全：

```text
【风格与角色固定层】
...

【参考图说明】
图1：...
图2：...

【场景】
...

【15秒分镜 / 动作时间轴】
0–Xs：...
X–Xs：...
...

【音频】
...

【关键约束】
...
```

动作时间轴的每一段优先描述“状态变化”，不要只是列动作名称。

## 失败时怎么改

若成片不理想，不先整份重写。优先找到唯一主故障：

- 动作跳跃 → 补中间状态；
- 结果动作不稳定 → 补动作后的衰减与最终姿态；
- 多角色混乱 → 减少同时动作 / 同时发声，重新分配行为选择；
- 角色漂移 → 恢复已验证固定层与参考图职责；
- 节奏拖沓 → 删除无意义节点，不压缩关键过渡；
- 15 秒内容太平 → 检查是否需要一次预期违背或更明确的升级节点；
- 信息过载 → 减少同一时间切片里的语言、动作或镜头事件。

新生成结果如能证明某条写法稳定有效，记录到后续实验 / 样本文件，不直接修改 Claude 原始方法论。

## 尚未验证：必须继续保留为开放问题

不得把以下问题擅自结论化：

1. 零台词写法对高能量 / 活泼角色的适用边界；
2. “减少台词”与“细化动作”各自对稳定性的独立贡献；
3. 完整反转结构在 8 秒以内的可执行下限；
4. 角色专属、世界观锚定、纯技术字段的自动分类规则。

这些问题应通过后续真实生成样本继续验证。
