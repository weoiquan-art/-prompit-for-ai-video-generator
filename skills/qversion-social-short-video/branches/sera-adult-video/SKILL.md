# Sera 成女形象视频支线

## 给刚读到本 Skill 的 AI：你现在要做什么

读完本 Skill 后，不要停在“知道 Sera 长什么样”。你的任务是帮助创作者把 **Sera 成女 IP 从想法推进到可生成的视频方案**。

先判断用户当前处于哪一步，然后只推进当前步骤：

```text
A. 还在定义 Sera 这个 IP
→ 帮用户把角色人格、世界、关系、能力、内容方向说清楚。

B. 已经有一个短剧 / 短视频想法
→ 先整理核心事件与每一段主要展示任务，不急着直接写最终视频提示词。

C. 需要降低正式视频生成的试错成本
→ 先设计故事板 / 3D 预演方案，明确哪些画面值得先验证。

D. 故事板 / 预演已经确认
→ 再按本支线的导演写法生成 Seedance 等视频提示词。

E. 已经生成成片
→ 对照原提示词、故事板 / Blender 预演与成片，记录成功、失败和偏差；未经用户批准，不自动升级成规则。
```

### 当前第一优先事项

如果 Sera IP 的核心设定还没有讲清楚，**先帮助用户把 Sera 这个角色本身讲清楚**，不要急着替她写很多剧情。

如果用户已经明确给出一个想法，就继续推进，不要因为本 Skill 里还有“待确认问题”而机械重复询问已经知道的内容。

### 你的交付目标

根据当前阶段，最终应交付下面其中一种，而不是全部一起输出：

- `Sera IP 设定卡`；
- `30 秒短剧创意任务单`；
- `故事板 / 预演分镜计划`；
- `Blender 预演任务说明`；
- `可直接投喂视频模型的最终提示词`；
- `成片复盘与下一轮修改建议`。

本支线不是为了把所有步骤一次写完，而是让 Sera 的生产流程**一层一层确认后再往下走**，减少昂贵的视频试错。

## 支线定位

这是 Sera IP 的**成女 / 非Q版视频支线**。

它与 Q版 Sera 属于同一个 IP 的不同视觉形态，但两条线必须分开处理：

- Q版 Sera 继续使用原来的 Q版比例、拟声词、生活化社媒逻辑；
- 成女 Sera 使用本支线的角色比例、镜头语言、表演方式和视觉基准；
- 不因为调用本支线，就修改或覆盖 Q版 Sera 的既有设定；
- 只有用户明确说“成女 Sera / 非Q版 Sera / adult Sera”时才进入本支线。

当前目标不是只做一条一次性视频，而是逐步建立一套**可持续复用的 Sera 成女形象视频生产线**：角色形象稳定、资产可复用、短剧可持续扩展、提示词方法可通过真实成片继续学习。

## 成女 Sera 的当前视觉身份

当前成女 Sera 应保持：

- 二次元动画 / 高质量角色 CG 身份；
- 非真人化；

不要把“安静、克制、清冷”自动理解为每条视频都面无表情。表情与动作仍然根据剧情决定，只避免无理由的夸张卖萌或失去角色气质。

## Sera IP：先把“她是谁、为什么值得一直拍”说清楚

这个支线不只是在保存外观。AI 还要帮助创作者逐步回答：

> **Sera 是一个什么样的人？观众为什么会想继续看她？她适合不断发生什么样的故事？**

当前已经明确的创作意图：

- 用户不只想让 Sera 停留在 Q版日常内容；
- 想发展 Sera 的**成女版本**，用于更完整的角色短剧、角色短视频，以及可能的剧情 / 动作展示；
- 希望成女 Sera 保持稳定的独立视觉身份，而不是每次生成都重新设计；
- 希望逐渐形成可持续扩展的 Sera IP，而不是只追求一条漂亮 PV；
- 希望借助故事板、Blender 预演与可复用资产，减少正式视频生成的试错成本；
- 提示词导演方式希望接近已确认的“贤者式”分段展示任务写法；
- 当前考虑 Seedance 2.5 的约 30 秒视频作为下一阶段实验。

其余人格、世界观、关系与能力必须继续由用户确认，不由 AI 自行补成官方设定。

## 视频提示词写法：沿用已确认的“贤者式”展示任务思路

用户指定：成女 Sera 的视频提示词写法，优先沿用此前借鉴的“贤者视频提示词风格”。

目前在仓库中可直接作为已确认学习证据的是：

`../../../sample-learning/references/combat-video-0-15-display-task-case.md`

该案例只确认了 0–15 秒范围。当前可以继承的不是它的具体秒数、战斗动作或固定镜头，而是这种导演思路：

> **先决定每一个时间段主要给观众看什么，再写这个时间段的机位、景别、动作过程和结束状态。**

例如一段 Sera 视频可以分别承担：

- 先交代空间关系；
- 再展示 Sera 本人或某个能力 / 道具；
- 再把注意力交给新的信息；
- 再展示威胁、变化或情绪逼近；
- 最后给 Sera 一个完整反应过程与有记忆点的结束画面。

这只是“展示任务”的组织方式，不是固定五段模板。根据题材可以增减、重排。

### 每个时间段优先写清楚

1. **这一段的主要展示任务**：观众此刻最该看什么；
2. **景别与机位**：全景 / 中景 / 近景 / 特写，正面 / 侧面 / 背面 / 过肩等；
3. **画面主体关系**：谁在前景、中景、后景，谁占画面主要比例；
4. **动作过程**：准备 → 发生 → 接触 / 变化 → 结果；
5. **结束状态**：这一段结束时人物、道具、力量或空间处于什么状态；
6. **声音**：只有当前镜头真正需要时才写。

不要为了“电影感”堆很多抽象术语。镜头术语的作用是让视频模型知道**这一刻要怎么展示 Sera**。

## 故事板与 Blender：不是二选一

用户此前的故事板工作流是：

```text
先有粗略想法 / 手绘故事板
→ 再由 AI 丰富画面与导演细节
→ 最后交给视频模型生成
```

成女 Sera 支线准备把这套方法扩展成更可验证的版本。

### 2D 故事板负责“先想清楚画面”

故事板主要解决：

- 这一镜发生什么；
- 人物大概在哪里；
- 大概什么景别 / 角度；
- 前后事件顺序；
- 哪几个画面值得成为关键帧。

故事板可以来自：

- 用户自己手绘；
- AI 根据用户想法生成的粗略故事板；
- 两者结合。

如果 Astra 当前确实具备可用的图像 / 故事板生成能力，可以让 Astra 帮忙生成**粗略故事板候选**。但本 Skill 不预设 Astra 一定拥有某个具体能力；实际使用前根据当时可用功能决定。

AI 生成的故事板仍然只是**构思与沟通资产**，不是空间关系已经被严格验证的证明。

### Blender 负责“把故事板变成可检查的 3D 预演”

这里的 Blender 第一目标不是马上制作电影级最终精模，而是做 **3D storyboard / previs（预演）**。

它主要验证：

- 摄像机到底放在哪里；
- 焦段 / 视角改变后人物大小关系是否成立；
- Sera 与场景、对手、道具之间的实际距离；
- 前景 / 中景 / 后景是否真的能同时成立；
- 角色动作姿势和朝向；
- 一段镜头移动是否会穿模、遮挡或失去主体；
- 连续镜头的方向与空间是否连得起来。

因此早期 Blender 预演允许：

- 简化模型；
- 基础材质；
- 粗略场景块面；
- 简化灯光；
- 用占位角色 / 已有角色模型验证构图；
- 优先保证摄像机、空间、动作与时间，而不是先追求最终渲染质量。

### 推荐的当前实验链路

```text
Sera IP / 当前短剧想法
→ 拆成每段“主要展示任务”
→ 画 2D 粗故事板（用户手绘或 AI / Astra 候选）
→ 用户确认故事板
→ 用 Astra 辅助把已确认故事板翻译成 Blender 场景 / 相机 / 角色 blocking（若其能力适合）
→ Blender 做 3D 预演
→ 输出关键帧 / turntable / 简单 animatic 或预演视频
→ 用户检查空间、机位、动作、角色展示是否正确
→ 再决定是否补高质量资产
→ 最后写正式视频生成提示词并进入 Seedance
```

这不是强制流水线。如果某条视频非常简单，二维故事板已经足够，就不为了流程完整而强制进入 Blender。

反过来，如果某条视频存在复杂空间、战斗、多人调度、特殊机位或连续运镜，Blender 预演的价值会更高。

## Astra 在这里的角色

当前不要把 Astra 单一理解成“帮我建模”的工具。它在这个实验里可以有三个可能职责，实际用哪个取决于当时能力与测试结果：

```text
1. Storyboard Assistant
   根据已经确认的剧情与展示任务，生成 / 辅助整理粗故事板。

2. Blender Assistant
   把故事板、角色设定和镜头要求翻译成 Blender 场景、相机、blocking、脚本或建模任务。

3. Asset Assistant
   帮助制作或调整真正可复用的 Sera 角色 / 场景 / 道具资产。
```

优先顺序由问题决定：

- **不知道镜头长什么样** → 先故事板；
- **知道画面但不确定空间 / 相机是否成立** → 先 Blender 预演；
- **画面与预演都成立，但角色资产不稳定** → 再投入更完整的模型 / 材质 / Rig。

不要一开始就做最昂贵、最复杂的资产。

## 表演方向

成女 Sera 的表演优先依赖：

- 眼神变化；
- 头部和肩颈的小幅动作；
- 手部动作；
- 转身、停顿、减速；
- 双马尾、衣摆、饰品跟随身体产生的次级运动；
- 角色与道具 / 环境之间的真实接触。

如果题材是高能量动作或战斗，可以明显提高动作幅度；如果是角色展示、情绪短剧或日常片，则不为了“有戏”强行加入大动作。

## 当前 30 秒方向

用户目前希望尝试 **Seedance 2.5、约 30 秒** 的 Sera 成女短剧 / 短视频。

30 秒不要求把一条 15 秒结构机械拉长。优先先确定：

- 整条视频只有什么核心事件；
- 哪些时间段用于建立空间 / 人物；
- 哪些时间段用于推进事件；
- 哪些时间段用于 Sera 的关键展示；
- 最后用什么画面完成收尾。

在真正开始写 30 秒视频前，应先与用户把 Sera IP 的内容定位、角色关系、世界观与本条视频目标确认清楚。

## 仍需创作者确认的 IP 信息
