# SKILL: Q版角色视频提示词方法论

> 一份独立、通用的视频生成提示词方法论，适用于任何 Q 版/拟人化角色的短视频内容创作。
> 不绑定特定 IP 世界观，可直接套用于不同角色项目。
> 本文档源自一次长期协作对话中反复试错、验证、迭代出的实战经验，
> 所有结论均基于创作者在生成端的实际观察反馈整理而成。

## 1. 核心原则：把提示词当分镜脚本写

**这是全篇最重要的一条原则：视频生成模型不是在"理解场景"，而是在"预测画面如何从一个状态过渡到下一个状态"。**

这意味着：
- 提示词的目标不是描述得"美"，而是描述得"清楚、无歧义、有因果"
- 模型不会自动脑补动作之间的过渡，除非明确写出来
- 一个模糊的整体描述，不如拆成几个明确的阶段描述

> 类比：不要把提示词当"画面说明书"，要当"分镜脚本 + 导演笔记"来写。

---

## 2. 分区一：风格与角色描述（固定层）

这部分内容在**同一角色的所有视频中应保持完全一致**，作用是锚定角色辨识度和画面基调，不随场景变化。

**应包含：**
- 拍摄风格（真实实拍 / 2D手绘 / 3D建模 / 二次元动画等）
- 镜头类型（第一人称POV手持 / 固定机位 / 环绕运镜等）
- 角色的固定外观特征（比例、描边风格、上色方式、发型处理方式）
- 角色的专属拟声词/说话方式（如果有）

**写法示例（模板）：**
```
[拍摄风格]，[镜头类型]，[环境光基调]，9:16竖屏。

角色为图X [角色名]，[比例关系，如头身比1:2]，[材质/描边风格]，
[表情/微表情描述]，口型与专属拟声词"[XX]"完美同步。
```

**为什么要固定：** 如果每次都重新描述角色外观，容易导致同一角色在不同视频里长得不一样。固定层应该像"角色设定表"一样可以直接复制粘贴。

---

## 3. 分区二：场景与分镜（可变层）

这部分是**每条视频都要重新写**的内容，包括具体场景、道具、和分镜时间轴。

**场景描述应包含：**
- 具体地点（不要只写"客厅"，要写"客厅地毯、门边鞋架、暖黄灯光"这种可视化细节）
- 光线氛围（时间段+光线质感，如"傍晚暖黄""正午顶光""深夜昏暗"）
- 关键道具的位置（如果分镜里会用到）

**为什么要具体：** 模糊的场景描述会让模型自由发挥背景细节，容易导致连续镜头之间场景不一致。

## 4. 分区三：动作转折的写法（全文档最核心的技术点）

### 4.1 原则

**不要写"做了什么"，要写"如何从一个状态变成另一个状态"。**

反例（模糊）：
> 角色跑过去抱住镜头

正例（拆解转折）：
> 小短腿蹬地加速 → 身体前倾 → 手臂张开 → 接触瞬间镜头微微后仰晃动 → 手臂环抱收紧 → 身体从紧绷逐渐放松定格

### 4.2 为什么有效

经协作验证：动作描述拆解得越细、越有物理因果链条，生成画面的稳定性越高。反之如果只写结果性动作（"抱住了""撞倒了"），模型容易在过渡阶段出现动作割裂、口型不同步等问题。

### 4.3 通用拆解公式

每个关键动作建议拆成三段：
```
【发力起点】角色开始动作的身体信号（比如蹬地、深吸气、肩膀绷紧）
【过渡状态】动作进行中的中间状态（不要跳过这一步）
【结果状态】动作完成后身体如何"停下来"（不是瞬间静止，而是有一个衰减过程）
```

## 5. 分区四：多角色协作与差异化

### 5.1 差异化应体现在"选择"，而非"台词内容"

多个角色在同一场景执行同一目标时，真正建立辨识度的不是"谁说了什么"，而是"谁选择做什么"。

**示例逻辑（角色行为模式表，供参考自行套用）：**

| 角色定位 | 行为模式 | 具体体现 |
|---|---|---|
| 冲动/主攻型 | 第一个行动，动作幅度最大 | 率先冲出、力度用尽、容易"闯祸" |
| 跟随/温和型 | 慢半拍但情绪稳定 | 跟随主攻型的动作，常担任收尾/安抚角色 |
| 克制/间接型 | 不直接参与肢体冲突，用环境或间接手段解决 | 语言极简甚至为零，动作干脆不拖泥带水 |

这套差异化逻辑的好处是：**即使不写大段台词，观众也能通过行为差异快速分辨角色性格。**

### 5.2 台词权限建议按角色人设分级

不是所有角色都需要"正常说话"。建议在角色设定阶段就明确：
- 哪些角色可以说完整句子/台词
- 哪些角色只能用拟声词
- 哪些角色应该完全不发声，只靠动作和呼吸表演

克制型角色减少甚至取消台词，往往比强行安排台词更符合人设，也更利于生成稳定性（参见分区三的逻辑）。

## 6. 分区五：音频与台词分配

### 6.1 格式建议

```
音频：[角色名] "[精确内容]"（语气方向，可选）
```

### 6.2 多角色发声的时序规则

**多个角色不建议同时发声**，尤其是在同一个2-3秒的镜头内。建议：
- 按角色出场顺序或情绪爆发顺序，错开0.5-1秒发声
- 仅在情绪高潮的结尾处，允许短暂的声音重叠作为强调

**原因：** 同一时间切片内堆叠过多语言信息，会分散模型的生成资源，间接影响画面质量（与分区三的核心逻辑同源）。

## 7. 分区六：情绪结构与叙事节奏

### 7.1 单一动作 vs 情绪反转结构

- **时长较短（约10秒以内）**：适合单一情绪弧线，如"平静→爆发→定格"，不建议塞入过多转折
- **时长较长（约15秒以上）**：建议至少加入一次"预期违背"的转折

**反转结构模板：**
```
建立预期（观众以为会发生A）
    ↓
反转（实际发生了B）
    ↓
角色反应/收尾（确认反转，给出情绪落点）
```

### 7.2 为什么反转结构更有传播力

单纯"角色做了一件可爱的事"容易被快速划走，而包含"预期违背"的内容更容易形成记忆点，因为观众的注意力会被"意外"锚定。

## 8. 分区七：素材图与角色标注

### 8.1 显式标注原则

如果输入多张参考图（角色图、道具图、变身前后形态图等），**必须用"图1/图2/图3"这种显式编号**，并在提示词正文中反复引用编号，而不是笼统写"参考图片"。

### 8.2 区分"精确复刻"与"氛围参考"

明确告诉模型：
- 哪些图需要**精确复刻造型**（通常是主体角色本身）
- 哪些图只是**氛围/道具参考**，不需要该图所有细节被逐一还原

混淆这两类图的用途，容易导致模型误判生成主体，或者过度还原不必要的背景细节。

### 8.3 风格模板迁移时的字段边界

当同一套"运镜/动作模板"套用到不同角色/世界观时（比如同一个运镜模板换一个角色使用），需要明确区分：
- **角色专属字段**（外观、武器、拟声词）→ 换角色时必须替换
- **世界观锚定字段**（天气、场景氛围、粒子特效风格）→ 必须跟随角色世界观整体替换，不能保留不匹配的环境描述
- **纯技术性字段**（镜头运动方式、构图节奏）→ 通常可以保持不变，跨角色复用

## 9. 分区八：时长与内容密度对照

| 时长 | 建议分镜数量 | 建议叙事结构 |
|---|---|---|
| 约8-10秒 | 3-5个动作阶段 | 单一情绪弧线，不建议加入完整转折 |
| 约15秒 | 5-7个动作阶段 | 可加入一次"遇阻→升级"式转折 |
| 约30秒+ | 建议拆分为多个独立分镜/镜头 | 每个镜头服务单一叙事目的，避免单镜头信息过载 |

**原则：** 时长越长，不代表应该把动作描述写得更啰嗦，而应该增加"叙事节点"的数量（即发生了几次有意义的状态变化），保持单个节点的描述精炼。

## 10. 常见误区速查表

| 误区 | 更好的做法 |
|---|---|
| 堆砌形容词描述画面"多美多可爱" | 描述具体的、可执行的动作和状态变化 |
| 多角色同时说很多台词 | 错开发声时间，克制型角色减少/取消台词 |
| "角色跑过去抱住"这种结果性描述 | 拆解成发力→过渡→结果三段式 |
| 换角色套用模板时只改角色描述 | 连场景氛围、特效风格一起按世界观整体替换 |
| 笼统写"参考图片" | 显式标注图1/图2/图3，并区分精确复刻与氛围参考 |
| 时长拉长但只是重复描述同一动作细节 | 时长拉长应对应增加叙事节点数量，而非单节点啰嗦 |

## 11. 尚未验证的开放问题

以下问题在实际协作中被观察到，但尚未经过严谨的单变量对比测试，供后续使用者自行验证：

1. **零台词写法的适用边界**：目前仅在"设定本身克制"的角色上验证有效，尚不确定高能量/活泼型角色是否反而需要保留台词/拟声词才能撑起表演张力
2. **变量隔离问题**：多数"效果更好"的观察案例中，"减少台词"和"细化动作描述"这两个变量往往是同时改变的，尚未做严格的单变量隔离测试，无法确定两者各自的贡献比重
3. **反转结构的时长下限**："遇阻→升级"式转折结构在极短时长（8秒以内）是否依然能被模型完整还原，还是会因节奏过快导致某个阶段被压缩丢失，需要专门测试
4. **风格模板字段边界的可复用性**：目前"哪些是角色专属字段、哪些是世界观锚定字段"的判断依赖创作者的人工经验，尚未形成可以直接套用的判断清单或自动化规则
