# Q版短视频：已验证生产备注

本文件用于记录用户在真实日常生成流程中确认的增量经验。不得覆盖 `claude-original-methodology.md` 原始经验；新规则作为生产层补充持续累积。

## 1. 区分“作者层标记”与“视频模型输出层”

### 结论

角色拟声词中的 `~`、`！` 等标点，主要用于帮助**负责写视频提示词的 AI**理解声音的情绪、长度和强度。

例如：

- `菲比啾比~~` → 理解为较长、柔软或撒娇的拉长音；
- `菲比！` → 理解为短促、兴奋、强调；
- `菲比啾比~~~！` → 理解为明显拉长且高兴、兴奋的呼喊；
- `糯糯~`、`Sela~` 同理。

这些属于**作者层语义标记**，不是要求最终视频生成提示词额外解释的技术语法。

### 最终视频提示词怎么写

最终交给 Seedance 等视频模型时：

- 可以直接保留角色实际要发出的拟声词文本；
- 可以直接写语气，例如“开心地拉长声音”“短促兴奋地喊”“轻轻软糯地发声”；
- 不需要再写“可以通过 `~`、`！` 改变情绪”“标点用于控制拉长音”等元说明；
- 不把面向提示词作者的规则说明混入面向视频模型的成品提示词。

### 两层示例

作者层理解：

```text
菲比：菲比啾比~~
= 温柔、满足、稍微拉长
```

最终视频提示词：

```text
音频：菲比贴近镜头，满足地拉长声音说“菲比啾比~~”。
```

而不是：

```text
可以通过“~”改变拉长音和情绪强弱。
```

### 原则

**内部规则帮助 AI 写得更准；最终 Prompt 只保留视频模型执行画面和声音真正需要的信息。**
