# Scene Sequence Director

位于 `idea-parser` 与 `shot-designer` 之间。只负责把一个完整场戏拆成可生产的镜头／生成片段，并让它们共享同一空间与因果；不替代逐镜摄影设计、微表演或最终 Prompt。

普通单镜或已经明确的 Q版日常 8–15 秒内容不必强制经过本 Skill。只有确实需要多镜头、多个生成片段、对白关系或跨镜连续性时才启用。

## 先确定场戏，而不是先数镜头

先回答：

- 场戏开始时，人物、关系、威胁与观众知道什么；
- 场戏结束时，哪些状态发生了不可逆变化；
- 观众在中间依次需要看懂哪些信息；
- 哪一个可见事件让下一镜成为必要；
- 哪些内容必须连续，哪些内容允许切开重做。

若删掉某镜后观众仍得到完全相同的信息与情绪，该镜应合并或删除。镜头数来自故事变化，不来自配额。

## 整场共享锚点

在逐镜设计前建立最小 Scene Anchor Map：

1. 固定结构与地标：门、墙、走廊、桌、出口、地平线等；
2. 人物起始标记与可行移动路径；
3. 摄影机主要所在一侧、视线轴或需要有意识跨越的轴线；
4. 主光方向，以及门外强光、火、屏幕等实际光源；
5. 风、尘、雨、烟、冲击波等外力的来向与传播方向；
6. 必须跨镜保持的道具、损伤、衣物、湿度、污染与声音状态。

共享锚点只锁会影响故事读法与连续性的事实，不把场景写成无意义的完整建筑说明。后续每镜只写变化量。

## 用镜头职能组织故事

可选职能包括：

- **关系镜头**：让观众同时看懂人物与目标／对手／环境的关系；
- **事件镜头**：让核心变化真正发生，并留下物理结果；
- **反应镜头**：让人物的身体先后变化证明事件的意义；
- **细节镜头**：只在细节会改变理解、悬念或决定时使用；
- **过渡镜头**：跨越地点、时间或状态，必须产生新信息。

职能不等于运镜。每镜可以固定，也可以移动；摄影机只做完成该镜任务所需的事。

## 强制写可见事实

每个故事节拍都要通过当前画面可见的外部证据成立：

```text
故事事实 → 外部刺激 → 第一个可见泄漏 → 身体反应
→ 环境／道具证明 → 可继承的结束状态
```

完整解释与 Sera 城门示例读取 `../../references/visible-facts-and-duration-examples.md`。逐镜交给 `../shot-designer/SKILL.md` 时，只传本镜机位能看见的节点。

## 双层时长

### 制作策划秒数

由策划者逐镜估算，用来验证故事容量、安排生成次数、预算重做成本与搭建剪辑。必须说明目标成片长度，并核对各镜预估之和；“约 4–6 秒”是合法的制作估算。

### 模型提示词时间控制

是否把秒数写进最终模型 Prompt 由当前镜头复杂度与模型能力决定：

- 简单动作、关键时点或清楚节拍需要精确落位时，可使用连续时间区间、时间点或相对时间；
- 复杂动作、长因果链、自然对白／表演或模型对精确时长不稳定时，保留镜头标签和清楚先后，不把策划估算伪装成模型必须逐秒服从的时间戳；
- 使用时间区间时，内容密度必须与区间容量匹配，并保持时间轴连续。

## 决定生成单元

优先考虑一次连续生成的情况：同一地点、同一时间、动作或对白连续推进，且连续性收益大于整段失败后的重生成成本。

优先拆成多个片段的情况：

- 换地点、换时间或视点发生明确跳跃；
- 某次揭示、反应或细节必须单独精确控制；
- 高复杂度动作会挤压对白、表情或物理反馈；
- 某镜失败时需要能局部重做；
- 数个几秒／几十秒镜头组合比一次长生成更容易完成完整故事。

是否支持 30 秒生成只是能力边界，不自动决定生产方法。真实项目可以混合：同场连续段用延续或长段，转折与复杂动作独立生成，再剪成一分钟以内或更长故事。

## 切镜条件

只有出现以下至少一项，才增加切镜：

- 观众需要获得新的关键事实；
- 同一机位无法同时看清事件与反应；
- 空间、时间或视点必须改变；
- 当前动作已经形成可承接的结束状态；
- 独立生成能显著降低关键镜头的失败成本。

每次切镜写清触发点、下一镜接收的状态与观众注意力落点。

## 输出

默认先交付场戏计划，不直接展开最终生成 Prompt：

1. 场戏目标与观众认知变化；
2. 入口状态与出口状态；
3. Scene Anchor Map；
4. 镜头／片段清单：制作预估秒数、镜头职能、可见事实、摄影机任务、切镜理由、结束状态；
5. 生成单元方案：哪些同段生成，哪些独立生成；
6. 交给 `shot-designer` 的逐镜 brief。

需要表格时使用 `../../assets/scene-sequence-plan-template.md`。
