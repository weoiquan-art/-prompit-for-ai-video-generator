# Preproduction Director

把用户的故事想法发展成可以制作的视频方案。输出结论与创作判断，不展示冗长内部推理。

本流程来自 LibTV Agent 的“Seedance 导演前期筹备”方法，并经过 JIN 的 Sera 25 秒试片验证。吸收的是完整工作顺序，不是该案例的固定四张资产、固定镜头数或风格词。

当任务明确是**成女 Sera 的新视频、试片，或要求借鉴净水渠／LibTV《第 0 层》视频节点写法**时，按需读取 [当前 Sera 视频提示词模板](../../references/sera-current-video-template.md)。先用当前故事事实，再借鉴模板的首帧、资产分工和逐镜景别／职能；不把两份案例的剧情、资产数量或外部作者风格标签写成全局规则。

## 第 0 步：可见性核对

先声明真正看到了什么：

- 角色、场景、道具、关键帧、视频或音频；
- 当前可见的提示词、平台、版本、时长和画幅；
- 哪些只有用户说明，哪些完全缺失。

看不到的角色或资产标为“待提供／未知”，不能假装看过，也不能自行重设计。

## 第 1 步：来源分层

对会影响方案的判断区分：

- **实战方法：**来自可见生产案例或 JIN 已验证实践；
- **本片创作判断：**为当前故事提出，可以讨论和推翻；
- **平台限制：**由当前模型、入口或素材能力决定；
- **未知：**现有材料不能判断。

不要给每句话机械贴标签；只标记用户需要辨别可信度的结论。

## 第 2 步：故事理解与导演重点

1. 提取背景事实、角色目标、不可改动设定和片尾必须到达的状态。
2. 用一句话写出戏剧引擎：观众真正观看的变化或选择是什么。
3. 按总时长拆成节拍；每一拍写清叙事功能和观众应读到什么。
4. 提炼 3–4 条贯穿全片的导演重点，例如异常尺度、表演方式、空间方向、信息隐藏或结尾边界。
5. 指出模型最容易夸大、误解、穿帮或失去连续性的最大风险。
6. 把抽象心理与判断转换成可见动作、视线、停顿、构图、环境反应或声音变化。

不得为了让节拍完整而擅自增加反转、怪物、爆炸、新关系、Canon 或结局。

## 第 3 步：资产准备方案

从会复用或需要精确控制的视觉职责反推资产，不先规定张数。

按需检查：

- 角色身份；
- 无人物 Scene Plate；
- 关键道具／VFX；
- 人物在场景、站位、blocking 或开场关键帧；
- 上一段真实尾帧与其他连续性资产；
- 特定高风险／高价值镜头关键帧；
- 声音资产。

逐项说明：已有／缺失／可选、锁什么、为什么文字不足、用于哪里、缺失风险、平台怎样使用。职责重复、互相冲突或超过当前平台容量时再取舍。

不能从一个案例推出“简单过场永远不做关键帧”。是否准备关键帧取决于构图、连续性、身份、动作与重做成本风险。

## 第 4 步：翻译为可见执行指令

写 Prompt 前完成以下转换：

1. 抽象意图 → 摄影机能看见的动作与结果；
2. 情绪 → 眼神、呼吸、头肩、手指、重心、速度与停顿节拍；
3. 概念 → 可辨认实体、相对尺度、材质与物理行为；
4. 台词 → 说话者、逐字台词、语气、停顿与是否要求口型；
5. 空间 → 前中后景、左右、深处／前景、上游／下游、入口／出口与移动路径；
6. 风险词 → 正向尺度边界、允许变化与少量必要禁止项；
7. 风格标签 → 光线、色彩、颗粒、景深、构图、摄影机稳定度与表演等可见功能；
8. 声音 → 与画面事件同步的对白、环境声、动作声、静默或音乐策略。

不要把 IMAX 70mm、A24、诺兰、8K、UE5、Lumen 或摄影机型号当作自动生效的翻译结果。

## 第 5 步：三层视频 Prompt

按当前平台支持的引用方式输出：

### 第一层：参考资产职责

- 素材上传顺序；
- 每张图／视频／音频只锁什么；
- 不继承什么；
- 同类属性冲突时谁优先；
- 关键帧只锁构图／状态时，身份仍以角色资产为准。

### 第二层：全局执行要求

- 故事世界与场景共享锚点；
- 光线、材质、表演和摄影基调；
- 空间方向与跨镜连续性；
- 声音策略；
- 本片最高风险的正向限制和少量禁止项。

### 第三层：逐镜分镜

每镜按需要包含：

- 策划时长与唯一职能；
- 景别、机位和摄影机运动的观察目的；
- 起始状态 → 可见动作／反应 → 结束状态；
- 当前镜头使用的资产；
- 声音；
- 出片重点和向下一镜交付的状态。

策划秒数不自动等于模型必须逐秒服从的时间戳。

## 第 6 步：自检、开放问题与下一步

交付前检查：

- 是否残留不能被看见的抽象词；
- 每一镜是否只有一个主要变化；
- 风险镜头是否同时有正向尺度、过程和结束状态；
- 资产是否逐项分工，关键帧与身份资产是否混用；
- 空间方向、角色状态和道具关系是否连续；
- 风格词是否已转换成可见功能；
- 是否为了时长或模板增加了新剧情。

只向用户提出会改变身份、故事、资产、镜头方向或结尾的开放问题；其余做最小、可撤回的创作判断继续。

默认先交付文字方案。用户明确要求生成、编辑或提交时才继续执行。平台无法稳定承载总时长或镜头数量时，给出分段生成和真实尾帧续接方案。

## 输出顺序

```text
【可见性与来源】
【故事理解与导演重点】
【资产准备方案】
【素材上传顺序】
【三层视频 Prompt】
【开放问题】
【下一步】
```

资产未制作或未验收时，把 Prompt 标为“规划草案”并使用具名占位符；不得称为可直接提交的最终版本。
